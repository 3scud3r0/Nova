# Decisões e limites de implementação

- A especificação referencia EDOs de uma conversa que não foi anexada. A cascata usa equações de difusão entre reservatórios com capacidades geométricas explicitadas no código; chama-se `DiffusiveCascade`, sem alegar reprodução exata das equações ausentes.
- `eps_ortho = ||U.T dW||` é exposto literalmente, mas não é uma condição necessária de retenção quando dW já aprendeu antes de consolidar U. `eps_update` mede a ortogonalidade da atualização efetiva.
- SVD incremental usa a representação comprimida `[U*S, X.T]`; não armazena todas as amostras históricas. Truncamento é uma ablação e perde a garantia completa.
- A entrega de código abrange as fases; aprovação científica é separada. Módulos sem ganho demonstrado permanecem experimentais, sem ativação automática no runtime padrão.

- A Fase 3 implementa a opção documentada de congelar camadas inferiores após a primeira tarefa. Em Split-MNIST o span completo satura; não foi demonstrada competitividade de acurácia com GPM. Não se reduz o rank silenciosamente para obter um resultado favorável.
- Split-MNIST e Permuted-MNIST executados usam amostras reduzidas; protocolos completos precisam de execução específica. O download oficial de CIFAR-100 foi bloqueado pelo proxy (CONNECT/HTTP 403 em `www.cs.toronto.edu`).
- O benchmark de controle usa DQN offline sobre as mesmas transições do modelo aprendido, porém ações discretas vs ações contínuas do CEM. Não é uma comparação definitiva de eficiência amostral online.
- O kernel Rust CPU é a trilha nativa solicitada no segundo documento. Há kernel Triton de referência, não executado sem CUDA. Energia/NVML e bitnet.cpp não foram medidos. A medição de memória considera o armazenamento dos pesos; não inclui todo o processo.
- EqProp foi implementado em uma energia quadrática convexa, com relaxamentos livre/forçado e comparação contra derivação implícita. Não se alega validação de EqProp não linear em escala.
- A simulação N2 usa compartimentos ramificados simplificados e canais Ca/Ih fenomenológicos. N1/N2 e o microcircuito não foram ajustados a registros biológicos. A banda dominante medida não atende, por si só, ao requisito de gama cortical realista.
- Encoders de imagem/áudio/texto, slots e fusão têm implementações e testes de operação. Treino multimodal completo, testes de ilusões e rastreamento visual de longo prazo não foram realizados. Perfis cluster/neuromórfico não são apresentados como implementações distribuídas prontas.
- A integração padrão usa um corpo linear 2D, além dos ambientes independentes de pêndulo e grid. Há um corpo pontual 3D com gravidade, colisões e controle de atraso, sem renderizador; adicionado na revisão final e não testado após a orientação de dispensar novos testes. Interlocutores sociais aprendidos e voz expressiva não estão implementados.
- As ablações dos neuromoduladores verificam efeitos dos sinais, não benefício comportamental geral. Regras de homeostase, Oja/STDP e poda estão disponíveis; não foi executado o ensaio de estabilidade de um milhão de ticks.
- A linguagem factual é um verbalizador controlado. O adaptador de LLM local gera rascunhos; ajuste LoRA, avaliação cega de estilo e naturalidade dependem de modelos/dados adicionais. OCR e transcrição requerem dependências externas opcionais.
- Identidade usa fontes estruturadas e revisão humana. A extração livre de fatos não é tratada como resolvida. Testes de memória usam dados fictícios, sem alegar validação de fidelidade de pessoa real.
- O pedido posterior de implementar todas as fases permite entregar os módulos experimentais após executar e registrar cada ensaio, mesmo quando o critério científico não é atingido. Isso não promove hipóteses reprovadas a resultados aceitos.

# NOVA

Plataforma experimental de aprendizado contínuo, previsão latente e simulação cognitiva, em Python 3.11+ e Rust/PyO3. Especificação fornecida em [docs/specification-v2.md](docs/specification-v2.md).

**Regra de honestidade:** nenhum módulo experimental é promovido ao fluxo padrão sem ganho mensurável contra baseline predefinido. Resultados negativos, limites de capacidade e dependências de hardware são parte da entrega. Inspiração biológica não equivale a validação contra dados biológicos.

## Instalação

```bash
python -m venv .venv
source .venv/bin/activate
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
pip install -e '.[dev]'
pytest -q
```

Use uma distribuição CUDA compatível do PyTorch para experimentos em GPU. O caminho CPU é suficiente para os testes e experimentos de bancada. Dados são baixados apenas pelos comandos de benchmark e ficam em `data/` (ignorado pelo Git).

## Experimentos

Execute da raiz do checkout:

```bash
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=1 python -m experiments.01_linear_nullspace_audit
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=1 python -m experiments.02_jepa_latent_world
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=1 python -m experiments.03_continual_split_mnist
python -m experiments.plot_reports
```

O Split-MNIST padrão usa 1.500 exemplos por tarefa e quatro épocas, cinco sementes, sem oráculo de tarefa no teste. Use `--samples 0` para todos os dados; `--dataset permuted-mnist` ou `--dataset split-cifar100` seleciona os demais protocolos. Resultados de dados reduzidos não estabelecem desempenho nos protocolos completos.

Os relatórios `reports/faseN.md` contêm as condições, métricas e limitações; os CSVs permitem comparar cada condição. O desvio reportado é amostral. Uma média misturando métodos não é uma comparação científica.

## Garantia linear

A atualização de `dW` é projetada no complemento de `U`. Retenção só vale no span calibrado, com entrada estável, precisão float64 e rank suficiente. Saturação impede aprender novas direções. A base ternária permanece congelada; o resíduo nunca é quantizado. Consulte [DEVIATIONS.md](DEVIATIONS.md).

## Fluxo completo

```bash
# Ambiente CPU e extensão Rust, quando o toolchain estiver disponível
bash scripts/setup.sh
source .venv/bin/activate

# Treino offline, antes de congelar as coordenadas da memória protegida
nova train-world --steps 900 --output checkpoints/world.npz
nova demo --ticks 100 --world checkpoints/world.npz
nova demo --ticks 100 --resume checkpoints/demo.npz
nova dashboard --metrics reports/demo.jsonl --output reports/dashboard.html

# Qualquer fase, executada explicitamente
nova benchmark 4
nova benchmark 5
nova benchmark 9
```

`nova demo` sem `--world` usa um encoder não treinado para demonstrar integração. O checkpoint inclui estado cognitivo, modelos, cascata, memórias, RNGs e estado do corpo virtual. A restauração usa NPZ/JSON, sem pickle. Alterar o encoder após consolidar memória é rejeitado, pois invalida as coordenadas protegidas.

Busca deliberada é habilitada por `--planning`. O modo determinístico usa orçamento de operações fixo; o modo com orçamento de tempo pode truncar a busca, sem prometer tempo real. Neuromoduladores e hipóteses opcionais não são promovidos automaticamente pelo demonstrador.

## Extensão Rust

Instale Rust >= 1.85 e execute:

```bash
maturin build --manifest-path nova-core/Cargo.toml --release --locked -o .cache/wheels
pip install .cache/wheels/*.whl
```

No ambiente preparado, o toolchain está em `.tools/cargo` e `.tools/rustup`:

```bash
export CARGO_HOME="$PWD/.tools/cargo"
export RUSTUP_HOME="$PWD/.tools/rustup"
export PATH="$CARGO_HOME/bin:$PATH"
```

A extensão exporta pesos ternários empacotados, Hadamard, AdEx, Kuramoto e cascata RK4, com Rayon. Falta da extensão gera erro explícito ao selecionar o backend Rust. O kernel Triton é opcional (`.[gpu]`) e requer CUDA.

## Identidade e linguagem

Veja [docs/identity.md](docs/identity.md) para o formato de `consent.json`, fontes, chaves, revisão e apagamento. Não há dados pessoais reais neste repositório. O cofre exige consentimento e mantém o rótulo de simulação; dados pessoais não treinam pesos compartilhados. A exclusão reconstrói o estado derivado do perfil, sem alegar apagar cópias externas.

OCR, ASR e LLM usam adaptadores opcionais com modelos locais. A saída factual padrão é determinística e fundamentada em fontes. O adaptador neural produz rascunhos não verificados, sujeitos a revisão.

Nenhum dado real é incluído no repositório. Os testes usam pessoas fictícias. Antes de ingerir dados, o responsável deve criar `private/consent.json` com autorização explícita e verificável fora do software. Exemplo de **estrutura**, deliberadamente não autorizado:

```json
{
  "subject_id": "identificador-pseudonimo",
```

"""Run: python -m experiments.01_linear_nullspace_audit."""

import numpy as np
from copy import deepcopy
from nova.continual import ProtectedLinear
from experiments.common import write_report


def main():
    rows = []
    for seed in range(5):
        rng = np.random.default_rng(seed)
        for rank in (4, 8, 16, 32):
            for alpha in (0, 0.25, 0.5, 0.75, 1):
                q, _ = np.linalg.qr(rng.normal(size=(32, 32)))
                xa = rng.normal(size=(64, rank)) @ q[:, :rank].T
                shared = round(alpha * rank)
                fresh = min(rank - shared, 32 - rank)
                basis = np.concatenate(
                    (q[:, :shared], q[:, rank : rank + fresh]), axis=1
                )
                xb = rng.normal(size=(64, basis.shape[1])) @ basis.T
                ya, yb = xa @ rng.normal(size=(32, 3)), xb @ rng.normal(size=(32, 3))
                model = ProtectedLinear(32, 3, seed=seed)
                for _ in range(150):
                    model.step(xa, ya, 0.08)
                naive = deepcopy(model)
                isolated = ProtectedLinear(32, 3, seed=seed)
                model.consolidate(xa)
                before, loss_before = model(xa), np.mean((model(xb) - yb) ** 2)
                for _ in range(150):
                    model.step(xb, yb, 0.08)
                    naive.step(xb, yb, 0.08)
                    isolated.step(xb, yb, 0.08)
                eps = model.retention_error(xa, before)
                assert eps < 1e-10
                rows.append(
                    dict(
                        seed=seed,
                        rank=rank,
                        alpha=alpha,
                        actual_new_dims=fresh,
                        eps_ret=eps,
                        eps_ortho=model.eps_ortho,
                        eps_update=model.eps_update,
                        free_dims=model.free_dims,
                        naive_ret=naive.retention_error(xa, before),
                        isolated_mse=np.mean((isolated(xb) - yb) ** 2),

                        mse_after=np.mean((model(xb) - yb) ** 2),

"""JEPA vs. future-mean and pixel autoencoder under independent distractors."""

import torch
from torch import nn
from nova.jepa import JEPA, ContextEncoder
from nova.environments import point_transitions
from experiments.common import write_report


def main():
    torch.set_num_threads(2)
    rows = []
    for seed in range(5):
        torch.manual_seed(seed)
        x, a, y, state = map(torch.from_numpy, point_transitions(seed=seed))
        tx, ta, ty, ts = map(torch.from_numpy, point_transitions(1024, 100 + seed))
        model = JEPA(12, 8, 2)
        optimizer = torch.optim.Adam(model.parameters(), lr=0.002)
        ae = nn.Sequential(
            ContextEncoder(12, 8), nn.Linear(8, 64), nn.SiLU(), nn.Linear(64, 12)
        )
        ae_opt = torch.optim.Adam(ae.parameters(), lr=0.002)
        for _ in range(900):
            idx = torch.randint(len(x), (128,))
            loss, _ = model.loss(x[idx], a[idx], y[idx])
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            model.target.update(model.context)
            loss_ae = (ae(x[idx]) - x[idx]).square().mean()
            ae_opt.zero_grad()
            loss_ae.backward()
            ae_opt.step()
        with torch.no_grad():
            z = model.context(tx)
            target = model.target(ty)
            mse = (model.predictor(z, ta) - target).square().mean().item()
            mean_mse = (target - model.target(y).mean(0)).square().mean().item()
            altered = tx.clone()
            altered[:, 4:] = torch.randn_like(altered[:, 4:])
            sensitivity = (model.context(altered) - z).square().mean().item()
            ae_sensitivity = (ae[0](altered) - ae[0](tx)).square().mean().item()
            train_z = torch.cat((model.context(x), torch.ones(len(x), 1)), 1)
            probe = torch.linalg.lstsq(train_z, state).solution
            state_mse = (
                (torch.cat((z, torch.ones(len(z), 1)), 1) @ probe - ts)
                .square()
                .mean()
                .item()
            )
            std = model.assert_noncollapsed(tx)
        rows.append(
            dict(
                seed=seed,
                latent_mse=mse,
                mean_baseline_mse=mean_mse,
                latent_std=std,
                distractor_sensitivity=sensitivity,
                autoencoder_sensitivity=ae_sensitivity,
                position_probe_mse=state_mse,
            )
        )
    write_report(
        2,
        rows,
        "Predição linear com oito distratores independentes; 900 passos, 5 sementes, teste independente.",
        "Aceite de bancada: std ≥ 0.05 e erro menor que média. Autoencoder usa reconstrução, portanto a sensibilidade é uma comparação de representações, não igualdade de objetivos. Pêndulo e grid têm testes funcionais; extrapolação JEPA nesses ambientes exige ensaios próprios.",
    )
    assert all(
        r["latent_mse"] < r["mean_baseline_mse"] and r["latent_std"] >= 0.05
        for r in rows
    )


if __name__ == "__main__":
    main()

"""Class-incremental MNIST: no task oracle; full data with --samples 0."""

import argparse
import csv
from pathlib import Path
from experiments.refresh_reports import parse
from copy import deepcopy
import numpy as np
import torch
from torch.nn import functional as F
from torchvision.datasets import MNIST, CIFAR100
from nova.continual.deep import (
    MLP,
    OnlineEWC,
    LayerwiseGPM,
    FrozenProtectedClassifier,
    continual_metrics,
)
from nova.continual import linear_cka
from experiments.common import write_report, paired


def data_tasks(dataset, samples, seed):
    gen = torch.Generator().manual_seed(seed)
    if dataset == "split-cifar100":
        train = CIFAR100("data", train=True, download=True)
        test = CIFAR100("data", train=False, download=True)
        x = torch.tensor(train.data).float().flatten(1) / 255
        tx = torch.tensor(test.data).float().flatten(1) / 255
        y = torch.tensor(train.targets)
        ty = torch.tensor(test.targets)
        groups = [range(i, i + 10) for i in range(0, 100, 10)]
    else:
        MNIST.mirrors = ["https://raw.githubusercontent.com/fgnt/mnist/master/"]
        train = MNIST("data", train=True, download=True)
        test = MNIST("data", train=False, download=True)
        x = train.data.flatten(1).float() / 255
        tx = test.data.flatten(1).float() / 255
        y = train.targets
        ty = test.targets
        groups = [range(i, i + 2) for i in range(0, 10, 2)]
    tasks = []
    if dataset == "permuted-mnist":
        groups = [range(10)] * 5
    for group in groups:
        idx = torch.where(torch.isin(y, torch.tensor(list(group))))[0]
        idx = idx[torch.randperm(len(idx), generator=gen)]
        if samples:
            idx = idx[:samples]
        tidx = torch.where(torch.isin(ty, torch.tensor(list(group))))[0]
        perm = (
            torch.randperm(x.shape[1], generator=gen)
            if dataset == "permuted-mnist"
            else torch.arange(x.shape[1])
        )
        tasks.append((x[idx][:, perm], y[idx], tx[tidx][:, perm], ty[tidx]))
    return tasks, int(y.max() + 1)


def train(model, x, y, epochs, generator, ewc=None, gpm=None):
    optimizer = torch.optim.SGD(model.parameters(), lr=0.08)
    for _ in range(epochs):
        for idx in torch.randperm(len(x), generator=generator).split(128):
            loss = F.cross_entropy(model(x[idx]), y[idx])
            if ewc:
                loss = loss + ewc.penalty(model)
            optimizer.zero_grad()
            loss.backward()
            if gpm:
                gpm.project(model)
            optimizer.step()


@torch.no_grad()
def accuracy(model, tasks):
    result = []
    for _, _, x, y in tasks:
        logits = (
            model.logits(x)
            if isinstance(model, FrozenProtectedClassifier)
            else model(x).numpy()
        )
        result.append(float((logits.argmax(1) == y.numpy()).mean()))
    return result


def main():
    Path("reports").mkdir(exist_ok=True)
    parser = argparse.ArgumentParser()
    parser.add_argument("--samples", type=int, default=1500)
    parser.add_argument("--epochs", type=int, default=4)
    parser.add_argument(
        "--dataset",
        choices=["split-mnist", "permuted-mnist", "split-cifar100"],
        default="split-mnist",
    )
    args = parser.parse_args()
    torch.set_num_threads(2)
    rows = []
    for seed in range(5):
        tasks, classes = data_tasks(args.dataset, args.samples, seed)
        torch.manual_seed(seed)
        initial_model = MLP(tasks[0][0].shape[1], 128, classes)
        initial = accuracy(initial_model, tasks)
        isolated = []
        for x, y, tx, ty in tasks:
            model = deepcopy(initial_model)
            train(model, x, y, args.epochs, torch.Generator().manual_seed(seed))
            isolated.append(accuracy(model, [(x, y, tx, ty)])[0])
        for method in ("finetune", "ewc", "replay", "gpm", "protected", "multitask"):
            model = deepcopy(initial_model)
            gen = torch.Generator().manual_seed(seed)
            ewc = OnlineEWC(model) if method == "ewc" else None
            gpm = LayerwiseGPM(model) if method == "gpm" else None
            matrices = []
            replay_x = []
            replay_y = []
            cka = 1.0
            reference = None
            free_dims = 129
            for task, (x, y, _, _) in enumerate(tasks):
                if method == "protected" and task > 0:
                    for _ in range(args.epochs):
                        for idx in torch.randperm(len(x), generator=gen).split(128):
                            model.train_batch(x[idx], y[idx])
                else:
                    xx, yy = x, y
                    if method == "replay" and replay_x:
                        xx, yy = torch.cat([x, *replay_x]), torch.cat([y, *replay_y])
                    if method == "multitask":
                        xx, yy = (
                            torch.cat([t[0] for t in tasks[: task + 1]]),
                            torch.cat([t[1] for t in tasks[: task + 1]]),
                        )
                    train(model, xx, yy, args.epochs, gen, ewc, gpm)
                if method == "protected":
                    if task == 0:
                        model = FrozenProtectedClassifier(model)
                    model.head.consolidate(model.features(x))
                    free_dims = model.head.free_dims
                elif ewc:
                    ewc.consolidate(model, x[:64], y[:64])
                elif gpm:
                    gpm.consolidate(model, x[:256])
                replay_x.append(x[:64])
                replay_y.append(y[:64])
                with torch.no_grad():
                    features = model.features(tasks[0][2][:256])
                    if isinstance(features, torch.Tensor):
                        features = features.numpy()
                if reference is None:
                    reference = features.copy()
                cka = linear_cka(reference, features)
                matrices.append(accuracy(model, tasks))
            metrics = continual_metrics(matrices, initial, isolated)
            rows.append(
                dict(
                    seed=seed,
                    method=method,
                    dataset=args.dataset,
                    samples_per_task=args.samples,
                    epochs=args.epochs,
                    cka=cka,
                    free_dims=free_dims if method == "protected" else "",
                    **metrics,
                )
            )
            np.save(
                f"reports/accuracy_{args.dataset}_{method}_{seed}.npy",
                np.asarray(matrices),
            )
            print(seed, method, metrics, flush=True)
    p = paired(
        [r["fm"] for r in rows if r["method"] == "protected"],
        [r["fm"] for r in rows if r["method"] == "finetune"],
    )
    previous = []
    if Path("reports/phase3.csv").exists():
        with Path("reports/phase3.csv").open() as stream:
            previous = [
                {k: parse(v) for k, v in row.items()}
                for row in csv.DictReader(stream)
                if row["dataset"] != args.dataset
            ]
    write_report(
        3,
        previous + rows,
        f"Resultados agrupados por dataset e método. Última execução: {args.dataset}: 5 sementes, {args.samples or 'todos'} exemplos por tarefa, {args.epochs} épocas, classificação global sem oráculo. p pareado de FM protegido vs fine-tuning: {p:.6g}.",
        "Métodos têm mesmos dados novos; replay/multitask usam exemplos adicionais explicitamente. GPM usa 95% de energia; proteção exata usa span completo. Saturação e plasticidade negativa são resultados válidos. Este ensaio reduzido não substitui os três benchmarks completos. Consulte CSV por método, não a média agregada entre métodos.",
    )

"""Memory/neuromod ablations and learned-model CEM vs offline DQN, shared transitions."""

import numpy as np
import torch
from torch import nn
from copy import deepcopy
from nova.memory import ModernHopfield, kwta
from nova.planning import LatentPlanner
from nova.neuromod import Neuromodulator
from experiments.common import write_report


def main():
    torch.set_num_threads(2)
    rows = []
    for seed in range(5):
        rng = np.random.default_rng(seed)
        torch.manual_seed(seed)
        patterns = kwta(rng.normal(size=(32, 256)), 0.05)
        patterns /= np.linalg.norm(patterns, axis=1, keepdims=True)
        h = ModernHopfield(patterns, 40)
        q = patterns + 0.3 * rng.normal(size=patterns.shape) / np.sqrt(256)
        masked = patterns * (rng.uniform(size=patterns.shape) > 0.5)
        noisy_acc = float(
            np.mean((h.retrieve(q) @ patterns.T).argmax(1) == np.arange(32))
        )
        masked_acc = float(
            np.mean((h.retrieve(masked) @ patterns.T).argmax(1) == np.arange(32))
        )
        # 2,048 identical one-step transitions available to both learned models.
        s = rng.uniform(-2, 2, (2048, 1))
        ai = rng.integers(0, 3, 2048)
        actions = np.array([-1.0, 0.0, 1.0])[ai, None]
        ns = s + 0.2 * actions
        rewards = -(ns[:, 0] ** 2)
        coef = np.linalg.lstsq(np.c_[s, actions, np.ones(len(s))], ns, rcond=None)[0]
        predictor = lambda z, a: np.c_[z, a, np.ones(len(z))] @ coef
        qnet = nn.Sequential(nn.Linear(1, 32), nn.Tanh(), nn.Linear(32, 3))
        target = deepcopy(qnet)
        opt = torch.optim.Adam(qnet.parameters(), lr=0.002)
        st = torch.tensor(s, dtype=torch.float32)
        nt = torch.tensor(ns, dtype=torch.float32)
        at = torch.tensor(ai)
        rt = torch.tensor(rewards, dtype=torch.float32)
        for i in range(800):
            idx = torch.randint(len(s), (128,))
            with torch.no_grad():
                value = rt[idx] + 0.95 * target(nt[idx]).max(1).values
            loss = (
                (qnet(st[idx]).gather(1, at[idx, None]).squeeze(1) - value)
                .square()
                .mean()
            )
            opt.zero_grad()
            loss.backward()
            opt.step()
            if i % 25 == 0:
                target.load_state_dict(qnet.state_dict())
        totals = {name: [] for name in ("cem", "random", "dqn")}
        for initial in (-1.5, -0.8, 0.8, 1.5):
            for name in totals:
                state = np.array([initial])
                total = 0.0
                planner = LatentPlanner(
                    predictor, lambda z: (z * z).sum(1), seed=seed, discount=0.95
                )
                for _ in range(15):
                    if name == "cem":
                        a = planner.plan(state).action
                    elif name == "random":
                        a = rng.uniform(-1, 1, 1)
                    else:
                        with torch.no_grad():
                            a = np.array(
                                [
                                    [-1.0, 0.0, 1.0][
                                        int(
                                            qnet(
                                                torch.tensor(state, dtype=torch.float32)
                                            ).argmax()
                                        )
                                    ]
                                ]
                            )
                    state = state + 0.2 * a
                    total -= float(state @ state)
                totals[name].append(total)
        # Each control signal is independently disabled; report its realized value.
        signals = {}
        for disabled in ("none", "NE", "DA", "ACh", "5HT"):
            mod = Neuromodulator(
                frozenset({"NE", "DA", "ACh", "5HT"} - {disabled})
            ).update(2.0, reward=1.0, uncertainty=0.7)
            signals[f"lr_without_{disabled}"] = mod.learning_rate(0.01)
            signals[f"consolidation_without_{disabled}"] = mod.consolidation()
            signals[f"sensory_without_{disabled}"] = mod.sensory_weight()
            signals[f"discount_without_{disabled}"] = mod.discount()
        rows.append(
            dict(
                seed=seed,
                recall_noise=noisy_acc,
                recall_mask=masked_acc,
                recall_chance=1 / 32,
                **{f"return_{k}": float(np.mean(v)) for k, v in totals.items()},
                **signals,
            )
        )
    write_report(
        4,
        rows,
        "Hopfield: 32 padrões, ruído 30% da norma e máscara Bernoulli 50%. CEM com modelo aprendido vs DQN offline e ações aleatórias, mesmas 2.048 transições, cinco sementes.",
        "CEM tem ações contínuas, DQN três ações discretas: não é equivalência de espaço de ações. Ablações dos neuromoduladores aqui verificam efeitos de controle, não ganho final em RL; permanecem opt-in. A cascata é um modelo de difusão declarado e validado analiticamente para M=2. Não se alega superioridade universal.",
    )


if __name__ == "__main__":
    main()

"""CPU end-to-end latency includes FFI conversion; GPU/energy require hardware."""

from time import perf_counter_ns
import numpy as np
import torch
from nova.core import TernaryLinear
from experiments.common import write_report


def latency(fn, repeats=30):
    for _ in range(5):
        fn()
    values = []
    for _ in range(repeats):
        start = perf_counter_ns()
        fn()
        values.append((perf_counter_ns() - start) / 1e6)
    return float(np.median(values))


def main():
    torch.set_num_threads(2)
    rows = []
    for seed in range(5):
        rng = np.random.default_rng(seed)
        for batch, d, n in ((1, 128, 64), (32, 128, 64), (8, 512, 128)):
            w = rng.integers(-1, 2, (d, n), dtype=np.int8)
            x = rng.normal(size=(batch, d))
            native = TernaryLinear(w)
            expected = x @ w
            np.testing.assert_allclose(native(x), expected, atol=1e-10)
            packed_ms = latency(lambda: native(x))
            for dtype in (torch.float16, torch.bfloat16):
                tx = torch.tensor(x, dtype=dtype)
                tw = torch.tensor(w, dtype=dtype)
                ms = latency(lambda: tx @ tw)
                rows.append(
                    dict(
                        seed=seed,
                        batch=batch,
                        input_dim=d,
                        output_dim=n,
                        dtype=str(dtype),
                        packed_ms=packed_ms,
                        torch_ms=ms,
                        speedup=ms / packed_ms,
                        packed_weight_bytes=native.nbytes,
                        dense_weight_bytes=w.size * 2,
                        packed_gops=2 * batch * d * n / (packed_ms * 1e6),
                        energy_joules="",
                        gpu_available=torch.cuda.is_available(),
                        bitnet_cpp="not installed",
                    )
                )
    write_report(
        5,
        rows,
        "Kernel CPU Rust/PyO3, quatro pesos por byte, acumulação por adição/subtração. Comparação contra torch.matmul fp16/bf16 CPU; cinco sementes, mediana de 30 execuções.",
        "Bytes referem-se apenas aos pesos, não a todo o processo. Latência inclui cópias da fronteira Python/Rust. Nenhuma GPU/NVML nem bitnet.cpp disponíveis: energia e comparação bitnet não medidas. Ganho de compactação não implica ganho de latência. Kernel Triton opcional implementado, mas não executado sem CUDA; ver DEVIATIONS.md.",
    )


if __name__ == "__main__":

import numpy as np
import torch
from nova.research import (
    PhaseOscillatorLayer,
    QuadraticEquilibriumPropagation,
    SheafCoherence,
)
from experiments.common import write_report


def main():
    rows = []
    for seed in range(5):
        on = PhaseOscillatorLayer(seed=seed)
        off = PhaseOscillatorLayer(seed=seed, coupling=0)
        for _ in range(1000):
            on.step()
            off.step()
        rng = np.random.default_rng(seed)
        eq = QuadraticEquilibriumPropagation(seed=seed)
        x = rng.normal(size=3)
        y = rng.normal(size=2)
        estimate = eq.gradient(x, y)
        b = torch.tensor(eq.B, requires_grad=True)
        state = torch.linalg.solve(torch.tensor(eq.A), b @ torch.tensor(x))
        loss = 0.5 * (torch.tensor(eq.P) @ state - torch.tensor(y)).square().sum()
        loss.backward()
        grad = b.grad.numpy()
        cosine = float(
            np.sum(grad * estimate) / np.linalg.norm(grad) / np.linalg.norm(estimate)
        )
        sheaf = SheafCoherence(4, 2, [(0, 1), (1, 2), (2, 3)])
        v = rng.normal(size=(4, 2))
        rows.append(
            dict(
                seed=seed,
                order_coupled=on.order,
                order_uncoupled=off.order,
                eqprop_gradient_cosine=cosine,
                coherence_before=sheaf.energy(v),
                coherence_after=sheaf.energy(sheaf.diffuse(v)),
            )
        )
    write_report(
        6,
        rows,
        "Kuramoto acoplado vs não acoplado; EqProp quadrático vs gradiente implícito PyTorch; difusão de feixe vs ausência de difusão.",
        "Verificações matemáticas passaram, mas não demonstram vantagem em tarefa cognitiva. Os três módulos são opt-in experimentais; não promovidos ao runtime padrão. EqProp quadrático não equivale a validação de uma rede não linear profunda.",
    )
    assert all(r["eqprop_gradient_cosine"] > 0.9 for r in rows)


if __name__ == "__main__":
    main()

from time import perf_counter
import numpy as np
from scipy.special import softmax
from nova.reasoning import (
    grid_search,
    TemperatureCalibrator,
    expected_calibration_error,
)
from nova.runtime import CognitiveRuntime, RuntimeConfig
from experiments.common import write_report


def main():
    rows = []
    for seed in range(5):
        rng = np.random.default_rng(seed)
        grids = []
        for _ in range(20):
            grid = rng.uniform(size=(12, 12)) < 0.2
            grid[0, :] = False
            grid[:, -1] = False
            grids.append(grid)
        for budget in (1, 32, 128, 256):
            start = perf_counter()
            solved = sum(
                grid_search(g, (0, 0), (11, 11), budget).verified for g in grids
            )
            rows.append(
                dict(
                    seed=seed,
                    condition="search",
                    budget=budget,
                    success=solved / len(grids),
                    seconds=perf_counter() - start,
                )
            )
        true_logits = rng.normal(size=(4000, 3))
        prob = softmax(true_logits, axis=1)
        labels = np.array([rng.choice(3, p=p) for p in prob])
        logits = true_logits * 3
        cal = TemperatureCalibrator().fit(logits[:2000], labels[:2000])
        before = expected_calibration_error(
            softmax(logits[2000:], axis=1), labels[2000:]
        )
        after = expected_calibration_error(cal.predict(logits[2000:]), labels[2000:])
        runtime = CognitiveRuntime(RuntimeConfig(seed=seed))
        for _ in range(100):
            runtime.tick()
        latencies = [m["latency_ms"] for m in runtime.metrics]
        rows.append(
            dict(
                seed=seed,
                condition="calibration_idle",
                ece_before=before,
                ece_after=after,
                temperature=cal.temperature,
                idle_latent_norm=float(np.linalg.norm(runtime.z)),
                tick_p95_ms=float(np.quantile(latencies, 0.95)),
            )
        )
    write_report(
        8,
        rows,
        "Busca BFS com verificador exato em 20 grids/seed; quatro orçamentos. Calibração por temperatura em partição separada e avaliação held-out. Ciclo ocioso e checkpoint determinístico testados.",
        "Mais expansões melhoram sucesso neste domínio finito, não provam raciocínio geral. O runtime integrado é um demonstrador com encoder inicial aleatório, a substituir por pesos treinados. Busca/neuromodulação opt-in. Latência é medida, não uma garantia de tempo real. Curiosidade ignora erro estacionário; ablações comportamentais amplas permanecem abertas.",
    )


if __name__ == "__main__":
    main()

                        subject_id=subject,

"""Machine-readable evidence, grouped conditions and reproducibility metadata."""

from pathlib import Path
from datetime import datetime, timezone
from importlib.metadata import version, PackageNotFoundError
import csv
import hashlib
import json
import platform
import numpy as np
from scipy.stats import ttest_rel

GROUPS = {
    1: ("rank", "alpha"),
    3: ("dataset", "method"),
    5: ("batch", "input_dim", "output_dim", "dtype"),
    7: ("condition", "current_pa"),
    8: ("condition", "budget"),
}


def source_digest():
    digest = hashlib.sha256()
    files = sorted(
        [
            *Path("nova").rglob("*.py"),
            *Path("experiments").glob("*.py"),
            *Path("nova-core/src").glob("*.rs"),
        ]
    )
    for file in files:
        digest.update(str(file).encode())
        digest.update(file.read_bytes())
    return digest.hexdigest()


def aggregate(rows, keys):
    return {
        key: {
            "mean": float(np.mean(values)),
            "std": float(np.std(values, ddof=1)) if len(values) > 1 else 0.0,
        }
        for key in keys
        if key != "seed"
        if (values := [r[key] for r in rows if isinstance(r.get(key), (float, int))])
    }


def write_report(
    phase: int, rows: list[dict], summary: str, limitations: str = ""
) -> None:
    root = Path("reports")
    root.mkdir(exist_ok=True)
    keys = sorted(set().union(*(r.keys() for r in rows)))
    with (root / f"phase{phase}.csv").open("w", newline="") as stream:
        writer = csv.DictWriter(stream, keys)
        writer.writeheader()
        writer.writerows(rows)
    group_keys = GROUPS.get(phase, ())
    conditions = {}
    for row in rows:
        label = (
            ", ".join(
                f"{key}={row.get(key, '')}"
                for key in group_keys
                if row.get(key, "") != ""
            )
            or "all seeds"
        )
        conditions.setdefault(label, []).append(row)
    grouped = {
        label: aggregate(group, [key for key in keys if key not in group_keys])
        for label, group in conditions.items()
    }
    packages = {}
    for package in ("numpy", "scipy", "torch", "pytest", "nova-native"):
        try:
            packages[package] = version(package)
        except PackageNotFoundError:
            packages[package] = "not installed"
    metadata = {
        "python": platform.python_version(),
        "platform": platform.platform(),
        "report_generated_at_utc": datetime.now(timezone.utc).isoformat(),
        "packages": packages,
        "report_source_sha256": source_digest(),
        "observations": len(rows),
        "groups": grouped,
    }
    (root / f"phase{phase}.json").write_text(
        json.dumps(metadata, indent=2, allow_nan=False)
    )
    table = "\n".join(
        f"| {label} | {metric} | {stats['mean']:.6g} | {stats['std']:.6g} |"
        for label, metrics in grouped.items()
        for metric, stats in metrics.items()
    )
    (root / f"fase{phase}.md").write_text(
        f"# Fase {phase}\n\n{summary}\n\n| Condição | Métrica | Média | Desvio amostral |\n|---|---|---:|---:|\n{table}\n\n{limitations}\n\nDados: `phase{phase}.csv`; grupos não misturam métodos ou orçamentos.\n"
    )


def paired(a, b):
    a, b = np.asarray(a), np.asarray(b)
    if np.allclose(a, b):
        return 1.0
    return float(ttest_rel(a, b).pvalue)

def parse(value):
    if value == "":
        return ""
    if value in ("True", "False"):
        return value == "True"
    try:
        return int(value)
    except ValueError:
        try:
            return float(value)
        except ValueError:
            return value

                    allow_pickle=False,

                    np.mean([a[j:-1, j].max() - a[-1, j] for j in range(len(a) - 1)])

//! Native CPU research kernels. Ternary coefficients use branches and add/subtract.
use numpy::{ndarray::Array2, PyArray2, PyReadonlyArray2};
use pyo3::{exceptions::PyValueError, prelude::*};
use rayon::prelude::*;

#[pyclass]
struct TernaryBlock {
    rows: usize,
    cols: usize,
    packed: Vec<u8>,
}

fn pack(weights: &[i8]) -> Result<Vec<u8>, &'static str> {
    let mut packed = vec![0u8; weights.len().div_ceil(4)];
    for (i, &w) in weights.iter().enumerate() {
        let code = match w { 0 => 0, 1 => 1, -1 => 2, _ => return Err("weights must be -1, 0, 1") };
        packed[i / 4] |= code << (2 * (i % 4));
    }
    Ok(packed)
}

#[pymethods]
impl TernaryBlock {
    #[new]
    fn new(weights: Vec<i8>, rows: usize, cols: usize) -> PyResult<Self> {
        if rows == 0 || cols == 0 || rows.checked_mul(cols) != Some(weights.len()) {
            return Err(PyValueError::new_err("invalid dimensions"));
        }
        Ok(Self { rows, cols, packed: pack(&weights).map_err(PyValueError::new_err)? })
    }
    #[getter]
    fn nbytes(&self) -> usize { self.packed.len() }
    fn packed_bytes(&self) -> Vec<u8> { self.packed.clone() }
    fn matmul<'py>(&self, py: Python<'py>, x: PyReadonlyArray2<'py, f64>) -> PyResult<Bound<'py, PyArray2<f64>>> {
        let a = x.as_array();
        if a.ncols() != self.rows { return Err(PyValueError::new_err("input dimension mismatch")); }
        let batch = a.nrows();
        let input: Vec<f64> = a.iter().copied().collect();
        let mut output = vec![0.; batch * self.cols];
        py.allow_threads(|| {
            output.par_chunks_mut(self.cols).enumerate().for_each(|(n, out)| {
                for k in 0..self.rows {
                    let value = input[n*self.rows+k];
                    for (j, result) in out.iter_mut().enumerate() {
                        let i = k*self.cols+j;
                        match (self.packed[i/4] >> (2*(i%4))) & 3 {
                            1 => *result += value,
                            2 => *result -= value,
                            _ => (),
                        }
                    }
                }
            });
        });
        let result = Array2::from_shape_vec((batch,self.cols),output).map_err(|e|PyValueError::new_err(e.to_string()))?;
        Ok(PyArray2::from_owned_array(py,result))
    }
}

fn hadamard(values: &mut [f64]) -> Result<(), &'static str> {
    if !values.len().is_power_of_two() { return Err("length must be a nonzero power of two"); }
    let mut width=1;
    while width<values.len() {
        for base in (0..values.len()).step_by(2*width) {
            for j in 0..width {
                let a=values[base+j]; let b=values[base+j+width];
                values[base+j]=a+b; values[base+j+width]=a-b;
            }
        }
        width*=2;
    }
    Ok(())
}

#[pyfunction]
fn fast_hadamard_transform(mut values: Vec<f64>, normalize: bool) -> PyResult<Vec<f64>> {
    hadamard(&mut values).map_err(PyValueError::new_err)?;
    if normalize { let scale=(values.len() as f64).sqrt(); for x in &mut values { *x/=scale; } }
    Ok(values)
}

#[pyfunction]
fn kuramoto_step(py: Python<'_>, theta: Vec<f64>, omega: Vec<f64>, adjacency: Vec<f64>, lag: Vec<f64>, coupling: f64, dt: f64) -> PyResult<Vec<f64>> {
    let n=theta.len();
    if n==0 || omega.len()!=n || adjacency.len()!=n*n || lag.len()!=n*n || dt<=0. {
        return Err(PyValueError::new_err("invalid Kuramoto dimensions/dt"));
    }
    Ok(py.allow_threads(|| (0..n).into_par_iter().map(|i| {
        let sum: f64=(0..n).map(|j|adjacency[i*n+j]*(theta[j]-theta[i]-lag[i*n+j]).sin()).sum();
        (theta[i]+dt*(omega[i]+coupling*sum/n as f64)).rem_euclid(std::f64::consts::TAU)
    }).collect()))
}


#[pyfunction]
#[allow(clippy::too_many_arguments)]
fn adex_step(py: Python<'_>, v: Vec<f64>, w: Vec<f64>, dendrite: Vec<f64>, refractory: Vec<f64>, basal: Vec<f64>, apical: Vec<f64>, adapt_a: Vec<f64>, adapt_b: Vec<f64>, tau: Vec<f64>, dt: f64, nmda: bool) -> PyResult<(Vec<f64>,Vec<f64>,Vec<f64>,Vec<f64>,Vec<bool>)> {
    let n=v.len();
    if n==0 || [w.len(),dendrite.len(),refractory.len(),basal.len(),apical.len(),adapt_a.len(),adapt_b.len(),tau.len()].iter().any(|&len|len!=n) || dt<=0. || dt>1. || tau.iter().any(|&t|t<=0.) {
        return Err(PyValueError::new_err("invalid AdEx arrays/dt (0 < dt <= 1 ms)"));
    }
    let results: Vec<(f64,f64,f64,f64,bool)>=py.allow_threads(|| (0..n).into_par_iter().map(|i| {
        let nmda_current=if nmda { 30./(1.+(-(dendrite[i]+40.)/5.).exp()) } else { 0. };
        let d=dendrite[i]+dt*(-5.*(dendrite[i]+70.)+2.*(v[i]-dendrite[i])+apical[i]+nmda_current)/100.;
        let mut new_w=w[i]+dt*(adapt_a[i]*(v[i]+70.)-w[i])/tau[i];
        let mut r=(refractory[i]-dt).max(0.);
        let mut new_v=if refractory[i]>0. { -58. } else {
            v[i]+dt*(-10.*(v[i]+70.)+20.*((v[i]+50.)/2.).min(10.).exp()-w[i]+2.*(dendrite[i]-v[i])+basal[i])/200.
        };
        let spike=new_v>=20.;
        if spike { new_v=-58.;new_w+=adapt_b[i];r=2.; }
        (new_v,new_w,d,r,spike)
    }).collect());
    Ok((results.iter().map(|r|r.0).collect(),results.iter().map(|r|r.1).collect(),results.iter().map(|r|r.2).collect(),results.iter().map(|r|r.3).collect(),results.iter().map(|r|r.4).collect()))
}

#[pyfunction]
fn cascade_rk4(py: Python<'_>, state: Vec<f64>, matrix: Vec<f64>, drive: Vec<f64>, reservoirs: usize, dt: f64) -> PyResult<Vec<f64>> {
    if reservoirs==0 || state.len()%reservoirs!=0 || drive.len()!=state.len()/reservoirs || matrix.len()!=reservoirs*reservoirs || dt<=0. {
        return Err(PyValueError::new_err("invalid cascade shapes/dt"));
    }
    Ok(py.allow_threads(|| {
        let mut result=state.clone();
        result.par_chunks_mut(reservoirs).enumerate().for_each(|(index,out)| {
            let s=&state[index*reservoirs..(index+1)*reservoirs];
            let f=|v:&[f64]| -> Vec<f64> {(0..reservoirs).map(|i| {
                let value:f64=(0..reservoirs).map(|j|matrix[i*reservoirs+j]*v[j]).sum();
                value+if i==0 {drive[index]} else {0.}
            }).collect()};
            let advance=|k:&[f64],factor:f64| -> Vec<f64> {s.iter().zip(k).map(|(v,d)|v+dt*factor*d).collect()};
            let k1=f(s);let k2=f(&advance(&k1,0.5));let k3=f(&advance(&k2,0.5));let k4=f(&advance(&k3,1.));
            for i in 0..reservoirs {out[i]=s[i]+dt*(k1[i]+2.*k2[i]+2.*k3[i]+k4[i])/6.;}
        });
        result
    }))
}

#[pymodule]
fn _native(m: &Bound<'_, PyModule>) -> PyResult<()> {
    m.add_class::<TernaryBlock>()?;
    m.add_function(wrap_pyfunction!(adex_step,m)?)?;
    m.add_function(wrap_pyfunction!(cascade_rk4,m)?)?;
    m.add_function(wrap_pyfunction!(fast_hadamard_transform,m)?)?;
    m.add_function(wrap_pyfunction!(kuramoto_step,m)?)?;
    Ok(())
}

"""Sparse E/PV/SST/VIP microcircuit and external-reference comparison tools."""

import csv
import numpy as np
from scipy import sparse
from scipy.signal import welch
from nova.neuron import AdExPopulation


class Microcircuit:
    def __init__(self, units=200, seed=0, backend="numpy", density=0.05):
        self.neurons = AdExPopulation(units, seed, backend)
        rng = np.random.default_rng(seed)
        types = self.neurons.types
        matrix = sparse.random(
            units,
            units,
            density=density,
            random_state=rng,
            data_rvs=lambda n: rng.uniform(5, 20, n),
        ).tocoo()
        keep = (matrix.row != matrix.col) & (
            (types[matrix.row] != 3) | (types[matrix.col] == 2)
        )
        rows, cols = matrix.row[keep], matrix.col[keep]
        sign = np.where(types[rows] == 0, 1.0, -1.0)
        self.weights = sparse.csr_matrix(
            (matrix.data[keep] * sign, (rows, cols)), shape=(units, units)
        )
        self.sst_weights = sparse.diags((types == 2).astype(float)) @ self.weights
        self.somatic_weights = self.weights - self.sst_weights
        self.trace = np.zeros(units)

    def step(self, drive=300.0, dt=0.1):
        self.trace *= np.exp(-dt / 5)
        basal = drive + self.somatic_weights.T @ self.trace
        apical = self.sst_weights.T @ self.trace
        spikes, state = self.neurons.step((basal, apical), dt=dt)
        self.trace += spikes
        return spikes, state

    def check_dale(self):
        for i in range(self.weights.shape[0]):
            row = self.weights.getrow(i).data
            if not (
                np.all(row >= 0) if self.neurons.types[i] == 0 else np.all(row <= 0)
            ):
                return False
        return True


def spectral_metrics(spikes, dt_ms):
    population = np.asarray(spikes, dtype=float).mean(axis=1) * 1000 / dt_ms
    f, p = welch(population, fs=1000 / dt_ms, nperseg=min(2048, len(population)))
    total = np.trapezoid(p, f)
    band = (f >= 30) & (f <= 80)
    return {
        "mean_rate_hz": float(population.mean()),
        "peak_hz": float(f[np.argmax(p)]),
        "gamma_fraction": float(np.trapezoid(p[band], f[band]) / total)
        if total
        else 0.0,
    }


def compare_reference(observed, reference_csv):
    """CSV metric,value,tolerance,source; data provenance is mandatory."""
    results = []
    with open(reference_csv, newline="") as stream:
        for row in csv.DictReader(stream):
            if not row.get("source"):
                raise ValueError("biological reference needs provenance")
            metric = row["metric"]
            expected = float(row["value"])
            tol = float(row["tolerance"])
            if tol < 0:
                raise ValueError("negative tolerance")
            actual = observed.get(metric)
            results.append(
                dict(
                    metric=metric,
                    observed=actual,
                    reference=expected,
                    tolerance=tol,
                    source=row["source"],
                    status="unrun"
                    if actual is None
                    else "passed"
                    if abs(actual - expected) <= tol
                    else "failed",
                )
            )
    return results


def load_connectome(path, nodes):
    """Edge CSV source,target,weight; preserve signed topology, no synthetic data label."""
    rows = []
    cols = []
    values = []
    with open(path, newline="") as stream:
        for e in csv.DictReader(stream):
            u, v = int(e["source"]), int(e["target"])
            if not 0 <= u < nodes or not 0 <= v < nodes:
                raise ValueError("connectome node out of range")
            rows.append(u)
            cols.append(v)
            values.append(float(e["weight"]))
    return sparse.csr_matrix((values, (rows, cols)), shape=(nodes, nodes))

from __future__ import annotations

import torch
from torch import nn
from torch.nn import functional as F

class MLP(nn.Module):
    def __init__(self, inputs=784, hidden=128, outputs=10):
        super().__init__()
        self.first = nn.Linear(inputs, hidden)
        self.last = nn.Linear(hidden, outputs)

    def features(self, x):
        return F.relu(self.first(x))

    def forward(self, x):
        return self.last(self.features(x))


class OnlineEWC:
    """Diagonal empirical Fisher from per-example gradients, accumulated per task."""

    def __init__(self, model, strength=20.0):
        self.strength = strength
        self.anchor = {n: p.detach().clone() for n, p in model.named_parameters()}
        self.fisher = {n: torch.zeros_like(p) for n, p in model.named_parameters()}

    def penalty(self, model):
        return (
            self.strength
            * 0.5
            * sum(
                (self.fisher[n] * (p - self.anchor[n]).square()).sum()
                for n, p in model.named_parameters()
            )
        )

    def consolidate(self, model, x, y):
        estimate = {n: torch.zeros_like(p) for n, p in model.named_parameters()}
        for xi, yi in zip(x, y):
            model.zero_grad()
            F.cross_entropy(model(xi[None]), yi[None]).backward()
            for n, p in model.named_parameters():
                estimate[n] += p.grad.detach().square() / len(x)
        for n, p in model.named_parameters():
            self.fisher[n] += estimate[n]
            self.anchor[n] = p.detach().clone()
        model.zero_grad()


class LayerwiseGPM:
    """Gradient projection on actual affine-layer inputs (bias coordinate included).

    Uses 95% activation energy by default; this is approximate retention and
    explicitly differs from the full-span float64 ProtectedLinear guarantee.
    """

    def __init__(self, model, energy=0.95):
        self.bases = [None, None]
        self.energy = energy

    @torch.no_grad()
    def consolidate(self, model, x):
        for i, activation in enumerate((x, model.features(x))):
            a = torch.cat((activation, torch.ones(len(x), 1)), 1).double().T
            old = self.bases[i]
            if old is not None:
                a -= old @ (old.T @ a)
            u, s, _ = torch.linalg.svd(a, full_matrices=False)
            if float(s.sum()) == 0:
                continue
            rank = (
                int(
                    torch.searchsorted(
                        s.square().cumsum(0) / s.square().sum(), self.energy
                    )
                )
                + 1
            )
            new = u[:, :rank]
            basis = new if old is None else torch.cat((old, new), 1)
            self.bases[i] = torch.linalg.qr(basis, mode="reduced")[0][:, : a.shape[0]]

    @torch.no_grad()
    def project(self, model):
        for layer, basis in zip((model.first, model.last), self.bases):
            if basis is None:
                continue
            grad = torch.cat((layer.weight.grad, layer.bias.grad[:, None]), 1).double()
            grad -= (grad @ basis) @ basis.T
            layer.weight.grad.copy_(grad[:, :-1])
            layer.bias.grad.copy_(grad[:, -1])


class FrozenProtectedClassifier:
    """Freeze the learned lower layer, transfer its head into continuous dW."""

    def __init__(self, model: MLP):
        self.encoder = model.first.requires_grad_(False)
        self.head = ProtectedLinear(model.last.in_features + 1, model.last.out_features)
        weights = (
            torch.cat((model.last.weight.T, model.last.bias[None]), 0).detach().numpy()
        )
        self.head.dW[:] = weights - self.head.W_base

    def features(self, x):
        with torch.no_grad():
            z = F.relu(self.encoder(x)).numpy().astype("float64")
        return np.c_[z, np.ones(len(z))]

    def logits(self, x):
        return self.head(self.features(x))

    def train_batch(self, x, y, lr=0.08):
        z = self.features(x)
        logits = self.head(z)
        exp = np.exp(logits - logits.max(1, keepdims=True))
        prob = exp / exp.sum(1, keepdims=True)
        prob[np.arange(len(y)), y.numpy()] -= 1
        grad = z.T @ prob / len(z)
        grad -= self.head.U @ (self.head.U.T @ grad)
        self.head.last_update = -lr * grad
        self.head.dW += self.head.last_update


def continual_metrics(accuracy, initial, isolated):
    """Rows = after task, columns = evaluation task; no task oracle at inference."""
    a = np.asarray(accuracy)
    n = len(a)
    return dict(
        acc=float(a[-1].mean()),
        fm=float(np.mean([a[j:-1, j].max() - a[-1, j] for j in range(n - 1)])),
        fwt=float(np.mean([a[j - 1, j] - initial[j] for j in range(1, n)])),
        plasticity=float(np.mean(np.diag(a) - isolated)),
    )

"""Float64 updates in the orthogonal complement of calibrated input directions."""

from __future__ import annotations
import numpy as np
from numpy.typing import ArrayLike, NDArray


class ProtectedLinear:
    """f(X) = X(W_base + dW); only dW learns, via g - U(U.T g).

    Protection concerns changes since consolidation, not U.T @ total dW = 0.
    Exact retention requires stable input coordinates and an untruncated basis.
    The covariance square-root update is a thin, incremental left-SVD update:
    SVD([U*S, X.T]), retaining singular values for subsequent batches.
    """

    def __init__(
        self,
        in_features: int,
        out_features: int,
        *,
        seed: int = 0,
        rank_max: int | None = None,
        energy_threshold: float | None = None,
    ):
        if min(in_features, out_features) < 1:
            raise ValueError("feature dimensions must be positive")
        self.in_features, self.out_features = in_features, out_features
        self.rank_max = in_features if rank_max is None else rank_max
        if not 0 <= self.rank_max <= in_features:
            raise ValueError("rank_max must be in [0, in_features]")
        if energy_threshold is not None and not 0 < energy_threshold <= 1:
            raise ValueError("energy_threshold must be in (0, 1]")
        self.energy_threshold = energy_threshold
        self.W_base = np.random.default_rng(seed).integers(
            -1, 2, (in_features, out_features), dtype=np.int8
        )
        self.W_base.flags.writeable = False
        self.dW = np.zeros((in_features, out_features), dtype=np.float64)
        self.U = np.empty((in_features, 0), dtype=np.float64)
        self.singular_values = np.empty(0, dtype=np.float64)
        self.last_update = np.zeros_like(self.dW)

    def _inputs(self, x: ArrayLike) -> NDArray[np.float64]:
        x = np.asarray(x, dtype=np.float64)
        if x.ndim != 2 or x.shape[1] != self.in_features or not np.isfinite(x).all():
            raise ValueError("expected finite [batch, in_features] inputs")
        return x

    def forward(self, x: ArrayLike) -> NDArray[np.float64]:
        x = self._inputs(x)
        return x @ self.W_base + x @ self.dW

    __call__ = forward

    def forward_addition_only(self, x: ArrayLike) -> NDArray[np.float64]:
        """Base uses gather-add; the continuous residual still uses dense matmul."""
        x = self._inputs(x)
        base = np.stack(
            [
                x[:, self.W_base[:, j] == 1].sum(1)
                - x[:, self.W_base[:, j] == -1].sum(1)
                for j in range(self.out_features)
            ],
            axis=1,
        )
        return base + x @ self.dW

    def consolidate(self, x: ArrayLike) -> None:
        x = self._inputs(x)
        if not len(x):
            raise ValueError("empty calibration batch")
        u, s, _ = np.linalg.svd(
            np.concatenate((self.U * self.singular_values, x.T), axis=1),
            full_matrices=False,
        )
        rank = int(np.count_nonzero(s > 1e-12 * s[0])) if s[0] > 0 else 0
        if self.energy_threshold is not None and rank:
            rank = min(
                rank,
                int(
                    np.searchsorted(
                        np.cumsum(s * s) / np.sum(s * s), self.energy_threshold
                    )
                )
                + 1,
            )
        rank = min(rank, self.rank_max)
        self.U, self.singular_values = u[:, :rank], s[:rank]

    def step(self, x: ArrayLike, y: ArrayLike, lr: float = 0.01) -> float:
        x = self._inputs(x)
        y = np.asarray(y, dtype=np.float64)
        if (
            not len(x)
            or y.shape != (len(x), self.out_features)
            or not np.isfinite(y).all()
            or lr < 0
        ):
            raise ValueError("invalid targets, batch, or learning rate")
        error = self(x) - y
        grad = x.T @ error / len(x)
        grad -= self.U @ (self.U.T @ grad)
        self.last_update = -lr * grad
        self.dW += self.last_update
        return float(np.mean(error**2))

    @property
    def free_dims(self) -> int:
        return self.in_features - self.U.shape[1]

    @property
    def eps_ortho(self) -> float:
        """Requested total-residual diagnostic; can be nonzero after consolidation."""
        return float(np.linalg.norm(self.U.T @ self.dW))

    @property
    def eps_update(self) -> float:
        return float(np.linalg.norm(self.U.T @ self.last_update))

    def retention_error(self, x: ArrayLike, reference: ArrayLike) -> float:
        return float(np.max(np.abs(self(x) - reference)))

    def expand(self, extra: int, *, seed: int = 0) -> None:
        """Recruit input coordinates; old samples must be padded with zeros."""
        if extra < 1:
            raise ValueError("extra must be positive")
        rng = np.random.default_rng(seed)
        self.W_base = np.vstack(
            (
                self.W_base,
                rng.integers(-1, 2, (extra, self.out_features), dtype=np.int8),
            )
        )
        self.W_base.flags.writeable = False
        self.dW = np.pad(self.dW, ((0, extra), (0, 0)))
        self.last_update = np.zeros_like(self.dW)
        self.U = np.pad(self.U, ((0, extra), (0, 0)))
        self.in_features += extra
        self.rank_max += extra


def linear_cka(x: ArrayLike, y: ArrayLike) -> float:
    """Centered linear CKA = ||X.T Y||² / (||X.T X|| ||Y.T Y||)."""
    x, y = np.asarray(x, dtype=float), np.asarray(y, dtype=float)
    x, y = x - x.mean(0), y - y.mean(0)
    denominator = np.linalg.norm(x.T @ x) * np.linalg.norm(y.T @ y)
    return float(np.linalg.norm(x.T @ y) ** 2 / denominator) if denominator else 0.0

from __future__ import annotations
import numpy as np


class LinearPoint:
    def __init__(self, seed=0, distractors=8, noise=0.01):
        self.rng = np.random.default_rng(seed)
        self.distractors, self.noise = distractors, noise
        self.state = np.zeros(4)

    def observe(self):
        return np.r_[
            self.state + self.rng.normal(0, self.noise, 4),
            self.rng.normal(size=self.distractors),
        ]

    def reset(self):
        self.state = self.rng.normal(0, 0.5, 4)
        return self.observe()

    def step(self, action):
        action = np.clip(np.asarray(action), -1, 1)
        self.state[2:] = 0.9 * self.state[2:] + 0.1 * action
        self.state[:2] += 0.1 * self.state[2:]
        return self.observe(), -float(self.state[:2] @ self.state[:2]), False, {}


class Pendulum:
    """theta'' = -g/l sin(theta) - damping*theta' + torque; semi-implicit Euler."""

    def __init__(self, seed=0, dt=0.02, noise=0.01):
        self.rng = np.random.default_rng(seed)
        self.dt, self.noise = dt, noise
        self.state = np.zeros(2)

    def observe(self):
        t, v = self.state
        return np.array([np.cos(t), np.sin(t), v]) + self.rng.normal(0, self.noise, 3)

    def reset(self):
        self.state = self.rng.uniform(-1, 1, 2)
        return self.observe()

    def step(self, action):
        t, v = self.state
        v += self.dt * (
            -9.81 * np.sin(t)
            - 0.1 * v
            + float(np.clip(np.asarray(action).item(), -2, 2))
        )
        self.state = np.array([t + self.dt * v, v])
        return self.observe(), -float(self.state @ self.state), False, {}


class GridWorld:
    ACTIONS = np.array([[0, 1], [0, -1], [1, 0], [-1, 0]])

    def __init__(self, size=7, seed=0, distractors=4):
        self.size, self.distractors = size, distractors
        self.rng = np.random.default_rng(seed)
        self.position = np.zeros(2, dtype=int)
        self.goal = np.array([size - 1, size - 1])

    def observe(self):
        return np.r_[
            self.position / (self.size - 1),
            self.goal / (self.size - 1),
            self.rng.normal(size=self.distractors),
        ]

    def reset(self):
        self.position[:] = 0
        return self.observe()

    def step(self, action):
        self.position = np.clip(
            self.position + self.ACTIONS[int(action)], 0, self.size - 1
        )
        done = bool(np.array_equal(self.position, self.goal))
        return self.observe(), 1.0 if done else -0.05, done, {}


def point_transitions(n=4096, seed=0, distractors=8):
    rng = np.random.default_rng(seed)
    state = rng.normal(size=(n, 4)).astype("float32")
    action = rng.uniform(-1, 1, (n, 2)).astype("float32")
    future = state.copy()
    future[:, 2:] = 0.9 * state[:, 2:] + 0.1 * action
    future[:, :2] += 0.1 * future[:, 2:]
    x = np.c_[state, rng.normal(size=(n, distractors))].astype("float32")
    y = np.c_[future, rng.normal(size=(n, distractors))].astype("float32")
    return x, action, y, state


class PointMass3D:
    """Minimal 3D virtual body with walls, gravity and bounded thrust.

    A research control environment, not a rendered graphics engine. Observation
    contains position, velocity, relative goal and independent sensor distractors.
    """

    def __init__(self, seed=0, dt=0.05, extent=3.0, distractors=4):
        if dt <= 0 or extent <= 0:
            raise ValueError("positive dt and extent required")
        self.rng = np.random.default_rng(seed)
        self.dt = dt
        self.extent = extent
        self.distractors = distractors
        self.state = np.zeros(6)
        self.goal = np.array([1.0, 1.0, 1.0])

    def observe(self):
        return np.r_[
            self.state,
            self.goal - self.state[:3],
            self.rng.normal(0, 0.05, self.distractors),
        ]

    def reset(self):
        self.state = np.r_[self.rng.uniform(-0.5, 0.5, 3), np.zeros(3)]
        return self.observe()

    def step(self, action):
        action = np.asarray(action, dtype=float)
        if action.shape != (3,) or not np.isfinite(action).all():
            raise ValueError("three finite actuator values required")
        acceleration = (
            3 * np.clip(action, -1, 1)
            - 0.2 * self.state[3:]
            + np.array([0.0, 0.0, -1.0])
        )
        self.state[3:] += self.dt * acceleration
        self.state[:3] += self.dt * self.state[3:]
        collided = np.abs(self.state[:3]) > self.extent
        self.state[:3] = np.clip(self.state[:3], -self.extent, self.extent)
        self.state[3:][collided] *= -0.5
        distance = float(np.linalg.norm(self.goal - self.state[:3]))
        done = distance < 0.1 and np.linalg.norm(self.state[3:]) < 0.2
        return (
            self.observe(),
            -distance - 0.01 * float(action @ action),
            bool(done),
            {"collision": bool(collided.any())},
        )


class DelayCompensatedController:
    """PD control with a constant-velocity forward prediction over actuator delay."""

    def __init__(self, kp=1.0, kd=0.5, delay=0.1):
        if delay < 0:
            raise ValueError("delay must be nonnegative")
        self.kp, self.kd, self.delay = kp, kd, delay

    def __call__(self, position, velocity, goal):
        prediction = np.asarray(position) + self.delay * np.asarray(velocity)
        return np.clip(
            self.kp * (np.asarray(goal) - prediction) - self.kd * np.asarray(velocity),
            -1,
            1,
        )

def atomic_write(path: Path, data: bytes):

def embedding(text, dimension=32):
    """Deterministic hashed bag of tokens; a retrieval baseline, not a language model."""
    result = np.zeros(dimension)
    for token in re.findall(r"\w+", text.casefold()):
        digest = hashlib.blake2b(token.encode(), digest_size=8).digest()
        index = int.from_bytes(digest[:4], "little") % dimension
        result[index] += 1 if digest[4] & 1 else -1
    return result / max(np.linalg.norm(result), 1.0)

    @contextmanager
    def _locked(self):
        fd = os.open(self.lock_path, os.O_CREAT | os.O_RDWR, 0o600)
        with os.fdopen(fd, "a+b") as stream:
            fcntl.flock(stream, fcntl.LOCK_EX)
            try:
                yield
            finally:
                fcntl.flock(stream, fcntl.LOCK_UN)

    def _audit(self, action):
        # No names, content, fact values or keys in access logs.
        row = {
            "profile": self.token,
            "actor": hashlib.sha256(self.actor.encode()).hexdigest(),
            "action": action,
            "at": now(),
        }
        fd = os.open(
            self.directory / "access.jsonl",
            os.O_APPEND | os.O_CREAT | os.O_WRONLY,
            0o600,
        )
        with os.fdopen(fd, "a") as stream:
            stream.write(json.dumps(row) + "\n")

    def _read(self):
        if not self.path.exists():
            return {"version": 1, "records": [], "reviewed": False, "derived": {}}
        blob = self.path.read_bytes()
        data = AESGCM(self._key).decrypt(blob[:12], blob[12:], self.token.encode())
        result = json.loads(data)
        if result.get("version") != 1:
            raise ValueError("unsupported vault version")
        return result

    def _write(self, data):
        nonce = os.urandom(12)
        raw = json.dumps(data, ensure_ascii=False, allow_nan=False).encode()
        atomic_write(
            self.path,
            nonce + AESGCM(self._key).encrypt(nonce, raw, self.token.encode()),
        )

    def _minimize(self, text, participants):
        text = str(text)
        for name in sorted(set(participants), key=len, reverse=True):
            if name and name != self.subject_id:
                alias = hmac.new(self._key, name.encode(), hashlib.sha256).hexdigest()[
                    :10
                ]
                text = re.sub(
                    re.escape(name), f"[terceiro:{alias}]", text, flags=re.IGNORECASE
                )
        text = re.sub(r"[\w.+-]+@[\w.-]+\.[A-Za-z]{2,}", "[email removido]", text)
        text = re.sub(r"(?<!\w)\+?\d[\d ()-]{7,}\d(?!\w)", "[telefone removido]", text)
        return text

    def _derive(self, records):
        facts = []
        events = []
        words = Counter()
        sentence_lengths = []
        values = []
        model = ProtectedLinear(32, 32, seed=0)
        model.dW[:] = -model.W_base.astype(float)
        for record in sorted(records, key=lambda r: r["id"]):
            source = record["id"]
            content = record["content"]
            words.update(re.findall(r"\w+", content.casefold()))
            sentence_lengths.extend(
                len(s.split()) for s in re.split(r"[.!?]+", content) if s.strip()
            )
            for fact in record["facts"]:
                facts.append(
                    {
                        **fact,
                        "subject": self.subject_id,
                        "source": source,
                        "timestamp": record["timestamp"],
                    }
                )
            for event in record["events"]:
                events.append({**event, "source": source})
            for value in record["values"]:
                values.append({**value, "source": source})
            x = embedding(content)[None]
            y = embedding(" ".join(f["value"] for f in record["facts"]))[None]
            for _ in range(20):
                model.step(x, y, 0.1)
            model.consolidate(x)
        style_allowed = "style" in json.loads(self.consent.path.read_text()).get(
            "purposes", []
        )
        return {
            "facts": facts,
            "events": sorted(events, key=lambda e: timestamp(e["timestamp"])),
            "style": {
                "common_words": words.most_common(20),
                "mean_sentence_words": float(np.mean(sentence_lengths))
                if sentence_lengths
                else 0.0,
            }
            if style_allowed
            else {},
            "values": values,
            "semantic_residual": model.dW.tolist(),
            "semantic_basis": model.U.tolist(),
            "free_dims": model.free_dims,
        }

    def ingest(self, source: dict[str, Any]):
        consent = self._check()
        if source.get("subject_id") not in [
            self.subject_id,
            *consent.get("aliases", []),
        ]:
            raise ConsentError("source is outside this subject scope")
        if source.get("kind") not in self.ALLOWED_KINDS:
            raise ValueError("unsupported source kind")
        if (
            not source.get("rights")
            or not source.get("id")
            or not source.get("content")
        ):
            raise ValueError("source id, content and rights are required")
        when = timestamp(source["timestamp"]).isoformat()
        participants = source.get("participants", [])
        clean = lambda text: self._minimize(text, participants)
        facts = []
        for fact in source.get("facts", []):
            if fact.get("subject_id", self.subject_id) != self.subject_id:
                raise ConsentError("third-party facts cannot enter this identity")
            confidence = float(fact.get("confidence", 1.0))
            if not 0 <= confidence <= 1:
                raise ValueError("invalid confidence")
            facts.append(
                {
                    "predicate": clean(fact["predicate"]),
                    "value": clean(fact["value"]),
                    "confidence": confidence,
                    "inference": bool(fact.get("inference", False)),
                }
            )
        events = []
        for event in source.get("events", []):
            events.append(
                {
                    "timestamp": timestamp(event.get("timestamp", when)).isoformat(),
                    "content": clean(event["content"]),
                    "location": clean(event.get("location", "")),
                    "participants": [self.subject_id],
                    "valence": float(np.clip(event.get("valence", 0.0), -1, 1)),
                    "anchor": bool(event.get("anchor", False)),
                }
            )
        values = []
        for value in source.get("values", []):
            if not value.get("evidence"):
                raise ValueError("value profile requires evidence")
            values.append(
                {
                    "dimension": clean(value["dimension"]),
                    "weight": float(np.clip(value["weight"], -1, 1)),
                    "evidence": clean(value["evidence"]),
                }
            )
        record = {
            "id": str(source["id"]),
            "kind": source["kind"],
            "rights": clean(source["rights"]),
            "timestamp": when,
            "content": clean(source["content"]),
            "facts": facts,
            "events": events,
            "values": values,
        }
        with self._locked():
            self._check()
            data = self._read()
            if any(r["id"] == record["id"] for r in data["records"]):
                raise ValueError(
                    "source id already exists; use a distinct correction source"
                )
            data["records"].append(record)
            data["derived"] = self._derive(data["records"])
            data["reviewed"] = False
            self._write(data)
            self._audit("ingest")
        return {
            "label": SIMULATION_LABEL,
            "source": record["id"],
            "review_required": True,
        }

    def ingest_file(self, path):
        self._check()  # Authorize before opening the data file.
        return self.ingest(json.loads(Path(path).read_text()))

    def review(self):
        self._check()
        with self._locked():
            data = self._read()
            data["reviewed"] = True
            self._write(data)
            self._audit("review")
        return {"label": SIMULATION_LABEL, "reviewed": True}

    def inspect(self):
        self._check()
        with self._locked():
            data = self._read()
            self._audit("inspect")
            return {"label": SIMULATION_LABEL, **data}

    def answer(self, predicate):
        self._check()
        with self._locked():
            data = self._read()
            self._audit("answer")
            if not data.get("reviewed"):
                return SIMULATION_LABEL + "\nOs dados aguardam revisão humana."
            facts = [
                f
                for f in data.get("derived", {}).get("facts", [])
                if f["predicate"] == predicate
            ]
            claims = [
                {
                    "text": f"{f['timestamp'][:10]}: {f['value']}",
                    "source": f["source"],
                    "inference": f["inference"],
                }
                for f in facts
            ]
            return OutputPolicy.render_claims(
                claims, identity_mode=True, consented=True
            )

    def timeline(self):
        data = self.inspect()
        return {
            "label": SIMULATION_LABEL,
            "events": data.get("derived", {}).get("events", []),
        }

    def delete_source(self, source_id):
        self._check(allow_revoked=True)
        with self._locked():
            data = self._read()
            before = len(data["records"])
            data["records"] = [r for r in data["records"] if r["id"] != source_id]
            data["derived"] = self._derive(data["records"])
            data["reviewed"] = False
            self._write(data)
            self._audit("delete_source")
            verified = not any(r["id"] == source_id for r in self._read()["records"])
        return {
            "label": SIMULATION_LABEL,
            "removed": before - len(data["records"]),
            "verified": verified,
            "derived_rebuilt": True,
        }

    def erase(self, revoke=True):
        self._check(allow_revoked=True)
        with self._locked():
            self.path.unlink(missing_ok=True)
            if revoke:
                consent = json.loads(self.consent.path.read_text())
                consent["revoked"] = True
                consent["revoked_at"] = now()
                atomic_write(self.consent.path, json.dumps(consent).encode())
            self._audit("erase")
        return {
            "label": SIMULATION_LABEL,
            "verified": not self.path.exists(),
            "scope": "active vault and its derived state; external copies are outside this store",
        }

"""Latent prediction with a stopped, exponential-moving-average target."""

from copy import deepcopy
import torch
from torch import nn
from torch.nn import functional as F


class ContextEncoder(nn.Sequential):
    def __init__(self, observation_dim: int, latent_dim: int, hidden: int = 64):
        super().__init__(
            nn.Linear(observation_dim, hidden), nn.SiLU(), nn.Linear(hidden, latent_dim)
        )


class TargetEncoder(nn.Module):
    def __init__(self, encoder: nn.Module):
        super().__init__()
        self.encoder = deepcopy(encoder).requires_grad_(False)

    def forward(self, x):
        with torch.no_grad():
            return self.encoder(x)

    @torch.no_grad()
    def update(self, encoder: nn.Module, decay: float = 0.99):
        for target, source in zip(
            self.encoder.parameters(), encoder.parameters(), strict=True
        ):
            target.lerp_(source, 1 - decay)
        for target, source in zip(
            self.encoder.buffers(), encoder.buffers(), strict=True
        ):
            target.copy_(source)


class LatentPredictor(nn.Module):
    def __init__(self, latent_dim: int, action_dim: int, hidden: int = 64):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(latent_dim + action_dim, hidden),
            nn.SiLU(),
            nn.Linear(hidden, latent_dim),
        )

    def forward(self, z, action):
        return self.net(torch.cat((z, action), dim=-1))


class JEPA(nn.Module):
    def __init__(
        self,
        observation_dim: int,
        latent_dim: int,
        action_dim: int,
        *,
        variance_weight: float = 1.0,
        covariance_weight: float = 0.01,
    ):
        super().__init__()
        self.context = ContextEncoder(observation_dim, latent_dim)
        self.target = TargetEncoder(self.context)
        self.predictor = LatentPredictor(latent_dim, action_dim)
        self.variance_weight, self.covariance_weight = (
            variance_weight,
            covariance_weight,
        )

    def loss(self, x, action, future):
        z = self.context(x)
        target = self.target(future)
        pred = self.predictor(z, action)
        prediction = F.smooth_l1_loss(pred, target)
        std = torch.sqrt(z.var(0, unbiased=False) + 1e-4)
        variance = F.relu(0.5 - std).mean()
        centered = z - z.mean(0)
        covariance = centered.T @ centered / max(len(z) - 1, 1)
        off_diagonal = covariance - torch.diag(torch.diag(covariance))
        loss = (
            prediction
            + self.variance_weight * variance
            + self.covariance_weight * off_diagonal.square().mean()
        )
        return loss, {
            "prediction": prediction.detach().item(),
            "latent_std": z.std(0).mean().detach().item(),
        }

    @torch.no_grad()
    def assert_noncollapsed(self, x, threshold=0.05):
        std = self.context(x).std(0).mean().item()
        if std < threshold:
            raise AssertionError(f"latent collapse: mean std {std:.6g} < {threshold}")
        return std

"""Optional GPU reference kernel: 2-bit weights, signed additions, no dense GEMM.

Requires Triton and CUDA. This intentionally simple kernel needs benchmarking;
compaction alone is not evidence of lower latency or energy.
"""

import torch


def pack_ternary(weights):
    if (
        weights.ndim != 2
        or not torch.isin(
            weights, torch.tensor([-1, 0, 1], device=weights.device)
        ).all()
    ):
        raise ValueError("expected ternary matrix")
    flat = weights.flatten()
    codes = torch.where(flat == -1, 2, flat).to(torch.uint8)
    padded = torch.zeros(
        ((len(codes) + 3) // 4) * 4, dtype=torch.uint8, device=weights.device
    )
    padded[: len(codes)] = codes
    padded = padded.reshape(-1, 4)
    return (
        padded[:, 0] | (padded[:, 1] << 2) | (padded[:, 2] << 4) | (padded[:, 3] << 6)
    )


def matmul(x, packed, out_features):
    if not x.is_cuda or not packed.is_cuda:
        raise ValueError("CUDA tensors required")
    if (
        x.ndim != 2
        or not x.is_contiguous()
        or packed.dtype != torch.uint8
        or out_features < 1
    ):
        raise ValueError("invalid tensor layout")
    if packed.numel() != (x.shape[1] * out_features + 3) // 4:
        raise ValueError("packed dimensions mismatch")
    import triton
    import triton.language as tl

    @triton.jit
    def kernel(X, W, Y, D: tl.constexpr, N: tl.constexpr, BLOCK: tl.constexpr):
        row = tl.program_id(0)
        cols = tl.program_id(1) * BLOCK + tl.arange(0, BLOCK)
        acc = tl.full((BLOCK,), 0, tl.float32)
        for k in range(D):
            index = k * N + cols
            bits = tl.load(W + index // 4, cols < N, other=0)
            code = (bits >> (2 * (index % 4))) & 3
            value = tl.load(X + row * D + k).to(tl.float32)
            acc += tl.where(code == 1, value, tl.where(code == 2, -value, 0.0))
        tl.store(Y + row * N + cols, acc, cols < N)

    y = torch.empty((len(x), out_features), device=x.device, dtype=x.dtype)
    kernel[(len(x), triton.cdiv(out_features, 64))](
        x, packed, y, x.shape[1], out_features, 64
    )
    return y

"""Associative retrieval, bounded working state, and source-preserving episodes."""

from __future__ import annotations
from collections import deque
from dataclasses import dataclass, field
import numpy as np
from scipy.special import softmax, logsumexp


def kwta(x, k):
    """Keep k largest magnitudes per row; ties are deterministic."""
    x = np.asarray(x)
    n = x.shape[-1]
    k = max(1, round(k * n)) if isinstance(k, float) else k
    if not 1 <= k <= n:
        raise ValueError("k outside [1, dimensions]")
    indices = np.argsort(np.abs(x), axis=-1, kind="stable")[..., -k:]
    out = np.zeros_like(x)
    np.put_along_axis(out, indices, np.take_along_axis(x, indices, -1), -1)
    return out


class ModernHopfield:
    """Recall softmax(beta * q X.T) X; E(q)=||q||²/2-logsumexp(beta Xq)/beta."""

    def __init__(self, patterns, beta=10.0):
        self.patterns = np.asarray(patterns, dtype=float)
        if self.patterns.ndim != 2 or not len(self.patterns) or beta <= 0:
            raise ValueError("invalid patterns/beta")
        self.beta = beta

    def retrieve(self, query, iterations=1):
        q = np.asarray(query, dtype=float)
        for _ in range(iterations):
            q = softmax(self.beta * (q @ self.patterns.T), axis=-1) @ self.patterns
        return q

    def energy(self, query):
        q = np.asarray(query, dtype=float)
        return (
            np.sum(q * q, axis=-1) / 2
            - logsumexp(self.beta * (q @ self.patterns.T), axis=-1) / self.beta
        )


@dataclass
class Episode:
    id: str
    embedding: np.ndarray
    content: str
    source: str
    timestamp: str
    location: str = ""
    participants: tuple[str, ...] = ()
    valence: float = 0.0
    surprise: float = 0.0
    anchor: bool = False
    revisions: list[str] = field(default_factory=list)


class EpisodicMemory:
    def __init__(self, capacity=1024, threshold=0.5):
        self.capacity, self.threshold = capacity, threshold
        self.episodes: list[Episode] = []

    def write(self, episode: Episode, force=False):
        if not episode.source:
            raise ValueError("episode requires source")
        if any(e.id == episode.id for e in self.episodes):
            raise ValueError("duplicate episode id")
        if not force and episode.surprise < self.threshold:
            return False
        if len(self.episodes) >= self.capacity:
            candidates = [e for e in self.episodes if not e.anchor]
            if not candidates:
                return False
            victim = min(candidates, key=lambda e: e.surprise + abs(e.valence))
            self.episodes = [e for e in self.episodes if e.id != victim.id]
        self.episodes.append(episode)
        return True

    def retrieve(self, query, limit=3, *, participant=None, location=None, before=None):
        candidates = [
            e
            for e in self.episodes
            if (participant is None or participant in e.participants)
            and (location is None or location == e.location)
            and (before is None or e.timestamp < before)
        ]
        q = np.asarray(query)
        norm = max(np.linalg.norm(q), 1e-12)
        return sorted(
            candidates,
            key=lambda e: float(
                q @ e.embedding / (norm * max(np.linalg.norm(e.embedding), 1e-12))
            ),
            reverse=True,
        )[:limit]

    def reconsolidate(self, episode_id, content):
        e = next(e for e in self.episodes if e.id == episode_id)
        e.revisions.append(e.content)
        e.content = content

    def sleep(self, learn, limit=32):
        chosen = sorted(
            self.episodes, key=lambda e: e.surprise + abs(e.valence), reverse=True
        )[:limit]
        for e in chosen:
            learn(e)
        # Exact duplicates only: conflicting or similar episodes must not be merged.
        seen = set()
        kept = []
        for e in self.episodes:
            key = (e.content, e.source, e.timestamp)
            if e.anchor or key not in seen:
                kept.append(e)
            seen.add(key)
        self.episodes = kept
        return len(chosen)


class WorkingMemory:
    def __init__(self, slots=7, dimensions=8, decay=0.95):
        if not 1 <= slots <= 10 or not 0 <= decay <= 1:
            raise ValueError("invalid working-memory configuration")
        self.state = np.zeros((slots, dimensions))
        self.decay = decay
        self.cursor = 0

    def update(self, value=None, gate=1.0):
        if not 0 <= gate <= 1:
            raise ValueError("gate must be in [0,1]")
        self.state *= self.decay
        if value is not None:
            self.state[self.cursor] = (1 - gate) * self.state[
                self.cursor
            ] + gate * np.asarray(value)
            self.cursor = (self.cursor + 1) % len(self.state)
        return self.state.copy()

class SemanticGraph:
    """Retain contradictory facts with distinct sources; never silently merge."""

    def __init__(self):
        self.facts = []

    def add(self, subject, predicate, value, source, confidence=1.0, timestamp=""):
        if not source or not 0 <= confidence <= 1:
            raise ValueError("source/confidence required")
        fact = dict(
            subject=subject,
            predicate=predicate,
            value=value,
            source=source,
            confidence=confidence,
            timestamp=timestamp,
        )
        if fact not in self.facts:
            self.facts.append(fact)

    def query(self, subject, predicate):
        return [
            f.copy()
            for f in self.facts
            if f["subject"] == subject and f["predicate"] == predicate
        ]

    )
    error_scale: float = 1.0
    surprise: float = 0.0
    reward_pe: float = 0.0
    uncertainty: float = 0.0
    patience: float = 0.5

    def update(self, error, reward=0.0, value=0.0, next_value=0.0, uncertainty=0.0):
        error = max(0.0, float(error))
        self.surprise = float(np.clip(error / max(self.error_scale, 1e-8), 0, 10))
        self.error_scale = 0.99 * self.error_scale + 0.01 * error
        self.reward_pe = float(np.clip(reward + 0.99 * next_value - value, -10, 10))
        self.uncertainty = float(np.clip(uncertainty, 0, 1))
        self.patience = float(
            np.clip(0.99 * self.patience + 0.01 * (1 - self.uncertainty), 0, 1)
        )
        return self

    def learning_rate(self, base):
        return base * (1 + min(self.surprise, 2)) if "NE" in self.enabled else base

    def write_threshold(self, base):
        return base / (1 + self.surprise) if "NE" in self.enabled else base

    def sensory_weight(self):
        return 0.5 + 0.5 * self.uncertainty if "ACh" in self.enabled else 0.5

    def consolidation(self):
        return float(1 / (1 + np.exp(-self.reward_pe))) if "DA" in self.enabled else 0.5

    def discount(self):
        return 0.9 + 0.099 * self.patience if "5HT" in self.enabled else 0.95

from __future__ import annotations
import numpy as np
from scipy.special import expit
from nova.continual import ProtectedLinear
from nova.memory import kwta


class RateNeuron:
    """N0: y=ReLU(v_b*(1+tanh(v_a))); k-WTA after apical gain."""

    def __init__(self, inputs=8, units=32, seed=0, k=0.1, apical_gain=True):
        self.basal = ProtectedLinear(inputs, units, seed=seed)
        self.apical = ProtectedLinear(inputs, units, seed=seed + 1)
        self.k, self.apical_gain = k, apical_gain
        self.state = np.zeros(units)

    def step(self, inputs, modulators=None, dt=0.1):
        if dt <= 0:
            raise ValueError("dt must be positive")
        basal, apical = inputs
        vb = self.basal(np.asarray(basal)[None])[0]
        va = self.apical(np.asarray(apical)[None])[0]
        output = vb * (1 + np.tanh(va)) if self.apical_gain else vb + va
        self.state = kwta(np.maximum(output, 0), self.k)
        return self.state.copy(), {"rate": self.state.copy()}


class AdExPopulation:
    """N1, ms/mV/pA/pF: C dv/dt=-gL(v-EL)+gL*Delta*exp((v-VT)/Delta)-w+gc(d-v)+I.

    tau_w dw/dt=a(v-EL)-w; dendritic conductance coupling, optional NMDA sigmoid.
    Euler dt <= 1 ms. Types: 0=E, 1=PV, 2=SST, 3=VIP. Sign belongs to outgoing
    synapses and is enforced by Microcircuit. Parameters are research defaults.
    """

    def __init__(self, units=100, seed=0, backend="numpy", nmda=False):
        if units < 1:
            raise ValueError("units must be positive")
        rng = np.random.default_rng(seed)
        self.types = np.zeros(units, dtype=int)
        self.types[int(0.8 * units) : int(0.9 * units)] = 1
        self.types[int(0.9 * units) : int(0.95 * units)] = 2
        self.types[int(0.95 * units) :] = 3
        self.a = np.choose(self.types, [2.0, 0.0, 4.0, 2.0])
        self.b = np.choose(self.types, [40.0, 0.0, 80.0, 20.0])
        self.tau = np.choose(self.types, [200.0, 30.0, 250.0, 150.0]) * rng.lognormal(
            0, 0.1, units
        )
        self.v = np.full(units, -70.0)
        self.w = np.zeros(units)
        self.dendrite = self.v.copy()
        self.refractory = np.zeros(units)
        self.backend, self.nmda = backend, nmda

    def step(self, inputs, modulators=None, dt=0.1):
        if not 0 < dt <= 1:
            raise ValueError("N1 requires 0 < dt <= 1 ms")
        basal, apical = inputs
        basal = np.broadcast_to(np.asarray(basal, dtype=float), self.v.shape)
        apical = np.broadcast_to(np.asarray(apical, dtype=float), self.v.shape)
        if not np.isfinite(basal).all() or not np.isfinite(apical).all():
            raise ValueError("nonfinite currents")
        if self.backend == "rust":
            from nova.core import require_native

            args = [
                a.tolist()
                for a in (
                    self.v,
                    self.w,
                    self.dendrite,
                    self.refractory,
                    basal,
                    apical,
                    self.a,
                    self.b,
                    self.tau,
                )
            ]
            result = require_native().adex_step(*args, dt, self.nmda)
            self.v, self.w, self.dendrite, self.refractory, spikes = map(
                np.asarray, result
            )
        elif self.backend == "numpy":
            v, w, d = self.v, self.w, self.dendrite
            self.dendrite = (
                d
                + dt
                * (
                    -5 * (d + 70)
                    + 2 * (v - d)
                    + apical
                    + (30 * expit((d + 40) / 5) if self.nmda else 0)
                )
                / 100
            )
            self.w = w + dt * (self.a * (v + 70) - w) / self.tau
            updated = (
                v
                + dt
                * (
                    -10 * (v + 70)
                    + 20 * np.exp(np.minimum((v + 50) / 2, 10))
                    - w
                    + 2 * (d - v)
                    + basal
                )
                / 200
            )
            self.v = np.where(self.refractory > 0, -58.0, updated)
            self.refractory = np.maximum(self.refractory - dt, 0)
            spikes = self.v >= 20
            self.v[spikes] = -58
            self.w[spikes] += self.b[spikes]
            self.refractory[spikes] = 2
        else:
            raise ValueError("backend must be numpy or rust")
        return spikes.copy(), self.state_dict()

    def state_dict(self):
        return {
            key: getattr(self, key).copy()
            for key in ("v", "w", "dendrite", "refractory", "types", "a", "b", "tau")
        }

    def load_state_dict(self, state):
        for key, value in state.items():
            if key not in self.state_dict() or np.shape(value) != self.v.shape:
                raise ValueError("invalid neuron checkpoint")
            setattr(self, key, np.asarray(value).copy())


class HodgkinHuxleyCompartments:
    """N2 small branched cable: Na/K HH gates plus phenomenological Ca and Ih.

    C dV/dt=I-gNa*m³h(V-50)-gK*n⁴(V+77)-gCa*c²(V-120)-gh*q(V+20)
             -gL(V+54.4)+sum gc(V_neighbor-V). Gates relax to voltage equilibria.
    Explicit RK4, dt <= .05 ms; not a fitted cellular morphology.
    """

    def __init__(self, compartments=4):
        if compartments < 1:
            raise ValueError("compartments must be positive")
        self.v = np.full(compartments, -65.0)
        self.gates = self._steady(self.v)[0]
        self.coupling = np.zeros((compartments, compartments))
        for i in range(1, compartments):
            self.coupling[i, (i - 1) // 2] = self.coupling[(i - 1) // 2, i] = 0.1

    @staticmethod
    def _ratio(x):
        x = np.asarray(x)
        out = np.ones_like(x)
        np.divide(x, -np.expm1(-x), out=out, where=np.abs(x) > 1e-7)
        return out

    def _steady(self, v):
        am = self._ratio((v + 40) / 10)
        bm = 4 * np.exp(-(v + 65) / 18)
        ah = 0.07 * np.exp(-(v + 65) / 20)
        bh = expit((v + 35) / 10)
        an = 0.1 * self._ratio((v + 55) / 10)
        bn = 0.125 * np.exp(-(v + 65) / 80)
        steady = np.stack(
            (
                am / (am + bm),
                ah / (ah + bh),
                an / (an + bn),
                expit((v + 20) / 6),
                expit(-(v + 80) / 8),
            )
        )
        tau = np.stack(
            (
                1 / (am + bm),
                1 / (ah + bh),
                1 / (an + bn),
                np.full_like(v, 5),
                np.full_like(v, 100),
            )
        )
        return steady, tau

    def step(self, inputs, modulators=None, dt=0.01):
        if not 0 < dt <= 0.05:
            raise ValueError("N2 requires 0 < dt <= .05 ms")
        basal, apical = inputs
        current = np.broadcast_to(np.asarray(basal, dtype=float), self.v.shape).copy()
        current[1:] += np.broadcast_to(np.asarray(apical, dtype=float), self.v.shape)[
            1:
        ]
        before = self.v.copy()
        state = np.vstack((self.v, self.gates))

        def f(s):
            v = s[0]
            m, h, n, c, q = s[1:]
            steady, tau = self._steady(v)
            ionic = (
                120 * m**3 * h * (v - 50)
                + 36 * n**4 * (v + 77)
                + 0.05 * c * c * (v - 120)
                + 0.02 * q * (v + 20)
                + 0.3 * (v + 54.4)
            )
            dv = current - ionic + self.coupling @ v - self.coupling.sum(1) * v
            return np.vstack((dv, (steady - s[1:]) / tau))

        k1 = f(state)
        k2 = f(state + dt * k1 / 2)
        k3 = f(state + dt * k2 / 2)
        k4 = f(state + dt * k3)
        state += dt * (k1 + 2 * k2 + 2 * k3 + k4) / 6
        self.v, self.gates = state[0], state[1:]
        return (before < 0) & (self.v >= 0), {
            "v": self.v.copy(),
            "gates": self.gates.copy(),
        }


def make_neuron(level="N0", **kwargs):
    return {"N0": RateNeuron, "N1": AdExPopulation, "N2": HodgkinHuxleyCompartments}[
        level
    ](**kwargs)

"""Modality encoders, streaming log-mel audio, slots and predictive inference."""

from __future__ import annotations
import math
import numpy as np
import torch
from torch import nn
from torch.nn import functional as F


class VisionEncoder(nn.Module):
    def __init__(self, latent_dim=16, channels=3):
        super().__init__()
        self.net = nn.Sequential(
            nn.Conv2d(channels, 16, 3, padding=1),
            nn.SiLU(),
            nn.Conv2d(16, 32, 3, stride=2, padding=1),
            nn.SiLU(),
            nn.AdaptiveAvgPool2d(1),
            nn.Flatten(),
            nn.Linear(32, latent_dim),
        )

    def foveate(self, image, gaze=(0.0, 0.0), radius=0.3):
        if radius <= 0:
            raise ValueError("radius must be positive")
        h, w = image.shape[-2:]
        yy, xx = torch.meshgrid(
            torch.linspace(-1, 1, h, device=image.device),
            torch.linspace(-1, 1, w, device=image.device),
            indexing="ij",
        )
        mask = torch.exp(-((xx - gaze[0]) ** 2 + (yy - gaze[1]) ** 2) / (2 * radius**2))
        low = F.interpolate(
            F.interpolate(image, size=(max(1, h // 8), max(1, w // 8)), mode="area"),
            size=(h, w),
            mode="bilinear",
            align_corners=False,
        )
        return image * mask + low * (1 - mask)

    def forward(self, image, gaze=(0.0, 0.0)):
        return self.net(self.foveate(image, gaze))


def mel_filters(sample_rate, n_fft, bands):
    hz_to_mel = lambda hz: 2595 * math.log10(1 + hz / 700)
    points = 700 * (
        10 ** (torch.linspace(0, hz_to_mel(sample_rate / 2), bands + 2) / 2595) - 1
    )
    freq = torch.linspace(0, sample_rate / 2, n_fft // 2 + 1)
    rising = (freq[None] - points[:-2, None]) / (points[1:-1, None] - points[:-2, None])
    falling = (points[2:, None] - freq[None]) / (points[2:, None] - points[1:-1, None])
    return torch.minimum(rising, falling).clamp_min(0)


class StreamingAudioEncoder(nn.Module):
    """Uncentered STFT -> log-mel -> causal temporal convolution; chunk-invariant."""

    def __init__(self, latent_dim=16, sample_rate=16000, n_fft=256, hop=128, bands=24):
        super().__init__()
        if not 0 < hop <= n_fft:
            raise ValueError("hop must be in (0,n_fft]")
        self.n_fft, self.hop, self.bands = n_fft, hop, bands
        self.register_buffer("filters", mel_filters(sample_rate, n_fft, bands))
        self.register_buffer("window", torch.hann_window(n_fft))
        self.register_buffer("samples", torch.empty(0))
        self.register_buffer("history", torch.zeros(1, bands, 2))
        self.conv = nn.Conv1d(bands, latent_dim, 3)

    def reset(self):
        self.samples = self.samples.new_empty(0)
        self.history.zero_()

    def forward(self, chunk):
        if chunk.ndim != 1:
            raise ValueError("expected mono one-dimensional samples")
        samples = torch.cat((self.samples, chunk))
        if len(samples) < self.n_fft:
            self.samples = samples.detach()
            return samples.new_empty((0, self.conv.out_channels))
        frames = samples.unfold(0, self.n_fft, self.hop)
        spectrum = torch.fft.rfft(frames * self.window).abs().square()
        mel = torch.log1p(spectrum @ self.filters.T).T[None]
        sequence = torch.cat((self.history, mel), dim=2)
        output = self.conv(sequence).squeeze(0).T
        self.history = sequence[:, :, -2:].detach()
        self.samples = samples[len(frames) * self.hop :].detach()
        return output


class TextEncoder(nn.Module):
    """UTF-8 byte tokens (padding=256) and a small recurrent sensory encoder."""

    def __init__(self, latent_dim=16):
        super().__init__()
        self.embedding = nn.Embedding(257, 32, padding_idx=256)
        self.gru = nn.GRU(32, latent_dim, batch_first=True)

    def forward(self, texts):
        encoded = [list(t.encode("utf-8")) or [256] for t in texts]
        if not encoded:
            raise ValueError("empty batch")
        lengths = torch.tensor([len(t) for t in encoded])
        tokens = torch.full(
            (len(encoded), int(lengths.max())),
            256,
            dtype=torch.long,
            device=self.embedding.weight.device,
        )
        for i, tokens_i in enumerate(encoded):
            tokens[i, : len(tokens_i)] = torch.tensor(tokens_i, device=tokens.device)
        packed = nn.utils.rnn.pack_padded_sequence(
            self.embedding(tokens), lengths, batch_first=True, enforce_sorted=False
        )
        _, state = self.gru(packed)
        return state[-1]


class SlotAttention(nn.Module):
    """Iterative slot competition; previous slots provide temporal object context."""

    def __init__(self, dimension=16, slots=4, iterations=3):
        super().__init__()
        self.initial = nn.Parameter(torch.randn(1, slots, dimension) * 0.1)
        self.key = nn.Linear(dimension, dimension)
        self.query = nn.Linear(dimension, dimension)
        self.value = nn.Linear(dimension, dimension)
        self.update = nn.GRUCell(dimension, dimension)
        self.iterations = iterations

    def forward(self, tokens, previous=None):
        slots = (
            self.initial.expand(len(tokens), -1, -1) if previous is None else previous
        )
        k, v = self.key(tokens), self.value(tokens)
        for _ in range(self.iterations):
            score = (
                self.query(slots) @ k.transpose(-1, -2) / math.sqrt(tokens.shape[-1])
            )
            attention = score.softmax(dim=1) + 1e-8
            attention = attention / attention.sum(-1, keepdim=True)
            updates = attention @ v
            slots = self.update(
                updates.reshape(-1, tokens.shape[-1]),
                slots.reshape(-1, tokens.shape[-1]),
            ).reshape_as(slots)
        return slots


class MultimodalFusion(nn.Module):
    def __init__(self, dimension=16):
        super().__init__()
        self.cross = nn.Linear(dimension, dimension, bias=False)

    def cross_prediction_loss(self, a, b):
        return F.smooth_l1_loss(self.cross(a), b.detach()) + F.smooth_l1_loss(
            self.cross(b), a.detach()
        )

    def forward(self, modalities, precision=None):
        stack = torch.stack(modalities, dim=1)
        weights = (
            torch.ones(stack.shape[:2], device=stack.device)
            if precision is None
            else precision
        )
        if torch.any(weights < 0) or torch.any(weights.sum(1) <= 0):
            raise ValueError("precision must be nonnegative with positive sum")
        return (stack * weights[:, :, None]).sum(1) / weights.sum(1, keepdim=True)


class PredictiveHierarchy:
    """E=1/2 sum_l pi_l ||r_l-W_l r_(l+1)||²; relax representations by gradient descent."""

    def __init__(self, dimensions=(8, 4, 2), seed=0):
        rng = np.random.default_rng(seed)
        self.weights = [
            rng.normal(0, 1 / np.sqrt(b), (a, b))
            for a, b in zip(dimensions[:-1], dimensions[1:])
        ]
        self.dimensions = dimensions

    def infer(self, observation, precision=None, steps=100, lr=0.03):
        x = np.asarray(observation, dtype=float)
        states = [x.copy()] + [
            np.zeros((*x.shape[:-1], d)) for d in self.dimensions[1:]
        ]
        precision = [1.0] * len(self.weights) if precision is None else precision
        if len(precision) != len(self.weights) or any(
            np.any(np.asarray(p) < 0) for p in precision
        ):
            raise ValueError("invalid precision")
        history = []
        for _ in range(steps):
            errors = [
                states[i] - states[i + 1] @ w.T for i, w in enumerate(self.weights)
            ]
            history.append(
                float(
                    sum(
                        np.sum(np.asarray(p) * e * e) / 2
                        for p, e in zip(precision, errors)
                    )
                )
            )
            gradients = []
            for i in range(1, len(states)):
                grad = -(errors[i - 1] * precision[i - 1]) @ self.weights[i - 1]
                if i < len(errors):
                    grad += errors[i] * precision[i]
                gradients.append(grad)
            for i, grad in enumerate(gradients, 1):
                states[i] -= lr * grad
        return states, history

    def learn(self, states, lr=0.001):
        for i, w in enumerate(self.weights):
            error = states[i] - states[i + 1] @ w.T
            w += (
                lr
                * np.atleast_2d(error).T
                @ np.atleast_2d(states[i + 1])
                / len(np.atleast_2d(error))
            )

"""Receding-horizon cross-entropy search and evidence accumulation."""

from dataclasses import dataclass
from time import perf_counter
import numpy as np


@dataclass
class Plan:
    action: np.ndarray
    cost: float
    iterations: int
    rollouts: int


class LatentPlanner:
    """CEM minimizes sum gamma**t * cost(z_t), subject to box action bounds."""

    def __init__(
        self,
        predictor,
        cost,
        action_dim=1,
        horizon=12,
        rollouts=128,
        iterations=4,
        elite_fraction=0.1,
        seed=0,
        discount=0.99,
    ):
        if (
            min(action_dim, horizon, rollouts, iterations) < 1
            or not 0 < elite_fraction <= 1
        ):
            raise ValueError("invalid search configuration")
        self.predictor, self.cost = predictor, cost
        self.action_dim, self.horizon, self.rollouts, self.iterations = (
            action_dim,
            horizon,
            rollouts,
            iterations,
        )
        self.elite_fraction, self.discount = elite_fraction, discount
        self.rng = np.random.default_rng(seed)

    def plan(self, z, budget_ms=None):
        start = perf_counter()
        mean = np.zeros((self.horizon, self.action_dim))
        std = np.ones_like(mean)
        best_cost = float("inf")
        best = np.zeros_like(mean)
        completed = 0
        for i in range(self.iterations):
            if (
                i
                and budget_ms is not None
                and (perf_counter() - start) * 1000 >= budget_ms
            ):
                break
            actions = np.clip(
                self.rng.normal(mean, std, (self.rollouts, *mean.shape)), -1, 1
            )
            actions[0] = best
            states = np.broadcast_to(z, (self.rollouts, len(z))).copy()
            costs = np.zeros(self.rollouts)
            for t in range(self.horizon):
                states = np.asarray(self.predictor(states, actions[:, t]))
                costs += self.discount**t * np.asarray(self.cost(states))
            elite = np.argsort(costs)[
                : max(1, int(self.rollouts * self.elite_fraction))
            ]
            if costs[elite[0]] < best_cost:
                best_cost = float(costs[elite[0]])
                best = actions[elite[0]].copy()
            mean = actions[elite].mean(0)
            std = np.maximum(actions[elite].std(0), 0.05)
            completed += 1
        return Plan(best[0].copy(), best_cost, completed, completed * self.rollouts)


def drift_diffusion(
    evidence, *, threshold=1.0, noise=0.1, dt=0.01, max_steps=1000, seed=0, urgency=0.0
):
    rng = np.random.default_rng(seed)
    evidence = np.asarray(evidence, dtype=float)
    state = np.zeros_like(evidence)
    for step in range(max_steps):
        state += evidence * dt + noise * np.sqrt(dt) * rng.normal(size=state.shape)
        if state.max() >= max(0.1, threshold - urgency * step * dt):
            return int(state.argmax()), (step + 1) * dt
    return int(state.argmax()), max_steps * dt

"""Budgeted search, exact arithmetic tools, and held-out confidence calibration."""

from __future__ import annotations
import ast
import operator
from collections import deque
from dataclasses import dataclass
import numpy as np

class Calculator:
    """Evaluate bounded arithmetic ASTs; no names, calls, attributes or code execution."""

    operations = {
        ast.Add: operator.add,
        ast.Sub: operator.sub,
        ast.Mult: operator.mul,
        ast.Div: operator.truediv,
        ast.Pow: operator.pow,
        ast.Mod: operator.mod,
    }

    def __call__(self, expression):
        if len(expression) > 512:
            raise ValueError("expression too long")
        tree = ast.parse(expression, mode="eval")
        if len(list(ast.walk(tree))) > 128:
            raise ValueError("expression too complex")

        def visit(node):
            if isinstance(node, ast.Constant) and type(node.value) in (int, float):
                value = node.value
            elif isinstance(node, ast.UnaryOp) and isinstance(
                node.op, (ast.UAdd, ast.USub)
            ):
                value = visit(node.operand) * (
                    1 if isinstance(node.op, ast.UAdd) else -1
                )
            elif isinstance(node, ast.BinOp) and type(node.op) in self.operations:
                a, b = visit(node.left), visit(node.right)
                if isinstance(node.op, ast.Pow) and abs(b) > 16:
                    raise ValueError("exponent budget exceeded")
                value = self.operations[type(node.op)](a, b)
            else:
                raise ValueError("only arithmetic is allowed")
            if (
                isinstance(value, complex)
                or not np.isfinite(value)
                or abs(value) > 1e100
            ):
                raise ValueError("result outside numeric budget")
            return value

        return visit(tree.body)


class ToolRegistry:
    def __init__(self):
        self.tools = {"calculator": Calculator()}

    def register(self, name, callback):
        if name in self.tools:
            raise ValueError("duplicate tool")
        self.tools[name] = callback

    def call(self, name, *args, **kwargs):
        if name not in self.tools:
            raise ValueError("tool not registered")
        return self.tools[name](*args, **kwargs)


@dataclass
class SearchResult:
    path: list[tuple[int, int]]
    expanded: int
    verified: bool


def grid_search(grid, start, goal, budget=1000):
    """Exact BFS verifier, bounded by expansions; more budget preserves found solutions."""
    grid = np.asarray(grid, dtype=bool)
    if grid.ndim != 2 or budget < 0:
        raise ValueError("invalid grid/budget")
    for p in (start, goal):
        if not 0 <= p[0] < grid.shape[0] or not 0 <= p[1] < grid.shape[1] or grid[p]:
            raise ValueError("invalid endpoint")
    start, goal = tuple(start), tuple(goal)
    queue = deque([start])
    parent = {start: None}
    expanded = 0
    while queue and expanded < budget:
        node = queue.popleft()
        expanded += 1
        if node == goal:
            path = []
            while node is not None:
                path.append(node)
                node = parent[node]
            return SearchResult(path[::-1], expanded, True)
        for delta in ((0, 1), (1, 0), (-1, 0), (0, -1)):
            nxt = (node[0] + delta[0], node[1] + delta[1])
            if (
                0 <= nxt[0] < grid.shape[0]
                and 0 <= nxt[1] < grid.shape[1]
                and not grid[nxt]
                and nxt not in parent
            ):
                parent[nxt] = node
                queue.append(nxt)
    return SearchResult([], expanded, False)


def hierarchical_route(grid, start, subgoals, budget=1000):
    path = [tuple(start)]
    used = 0
    for goal in subgoals:
        result = grid_search(grid, path[-1], tuple(goal), max(0, budget - used))
        used += result.expanded
        if not result.verified:
            return SearchResult([], used, False)
        path.extend(result.path[1:])
    return SearchResult(path, used, True)


def expected_calibration_error(probabilities, labels, bins=10):
    p = np.asarray(probabilities)
    labels = np.asarray(labels)
    if (
        p.ndim != 2
        or len(p) == 0
        or len(labels) != len(p)
        or np.any(p < 0)
        or not np.allclose(p.sum(1), 1)
    ):
        raise ValueError("invalid probability distribution")
    confidence = p.max(1)
    correct = p.argmax(1) == labels
    value = 0.0
    index = np.minimum((confidence * bins).astype(int), bins - 1)
    for i in range(bins):
        selected = index == i
        if selected.any():
            value += selected.mean() * abs(
                confidence[selected].mean() - correct[selected].mean()
            )
    return float(value)


class TemperatureCalibrator:
    def __init__(self):
        self.temperature = 1.0

    def fit(self, logits, labels):
        logits = np.asarray(logits)
        labels = np.asarray(labels)

        def nll(log_temperature):
            p = softmax(logits / np.exp(log_temperature), axis=1)
            return -np.log(np.maximum(p[np.arange(len(p)), labels], 1e-12)).mean()

        result = minimize_scalar(nll, bounds=(-4, 4), method="bounded")
        if not result.success:
            raise RuntimeError("calibration did not converge")
        self.temperature = float(np.exp(result.x))
        return self

    def predict(self, logits):
        return softmax(np.asarray(logits) / self.temperature, axis=1)

class PhaseOscillatorLayer:
    """dtheta_i/dt=omega_i+K/N sum_j A_ij sin(theta_j-theta_i-alpha_ij)."""

    def __init__(
        self, size=32, coupling=2.0, seed=0, adjacency=None, lag=None, backend="numpy"
    ):
        rng = np.random.default_rng(seed)
        self.theta = rng.uniform(-np.pi, np.pi, size)
        self.omega = rng.normal(0, 0.1, size)
        self.coupling = coupling
        self.adjacency = (
            np.ones((size, size))
            if adjacency is None
            else np.asarray(adjacency, dtype=float)
        )
        self.lag = (
            np.zeros((size, size)) if lag is None else np.asarray(lag, dtype=float)
        )
        if self.adjacency.shape != (size, size) or self.lag.shape != (size, size):
            raise ValueError("invalid coupling shape")
        self.backend = backend

    def step(self, dt=0.01):
        if dt <= 0:
            raise ValueError("dt must be positive")
        if self.backend == "rust":
            from nova.core import require_native

            self.theta = np.asarray(
                require_native().kuramoto_step(
                    self.theta.tolist(),
                    self.omega.tolist(),
                    self.adjacency.ravel().tolist(),
                    self.lag.ravel().tolist(),
                    self.coupling,
                    dt,
                )
            )
        elif self.backend == "numpy":
            derivative = self.omega + self.coupling * np.mean(
                self.adjacency
                * np.sin(self.theta[None, :] - self.theta[:, None] - self.lag),
                axis=1,
            )
            self.theta = (self.theta + dt * derivative) % (2 * np.pi)
        else:
            raise ValueError("backend must be numpy or rust")
        return self.theta.copy()

    @property
    def order(self):
        return float(abs(np.exp(1j * self.theta).mean()))


class QuadraticEquilibriumPropagation:
    """E(s)=1/2 s.T A s-s.T Bx; C=1/2 ||P s-y||².

    Free and nudged equilibria are reached by actual relaxation. Parameter
    gradient is -(s_beta-s_free)x.T/beta, compared to implicit backprop.
    A is symmetric positive definite; this is a small quadratic validation model.
    """

    def __init__(self, inputs=3, state=5, outputs=2, seed=0):
        rng = np.random.default_rng(seed)
        m = rng.normal(0, 0.1, (state, state))
        self.A = np.eye(state) + m.T @ m
        self.B = rng.normal(0, 0.2, (state, inputs))
        self.P = np.eye(state)[-outputs:]
        self.last_iterations = (0, 0)

    def relax(
        self, x, y=None, beta=0.0, initial=None, tolerance=1e-11, max_steps=10000
    ):
        if beta < 0:
            raise ValueError("beta must be nonnegative")
        s = np.zeros(len(self.A)) if initial is None else initial.copy()
        matrix = self.A + beta * self.P.T @ self.P
        drive = self.B @ x + (beta * self.P.T @ y if y is not None else 0)
        dt = 0.8 / np.linalg.eigvalsh(matrix).max()
        for i in range(max_steps):
            gradient = matrix @ s - drive
            if np.linalg.norm(gradient) < tolerance:
                return s, i
            s -= dt * gradient
        raise RuntimeError("equilibrium did not converge")

    def gradient(self, x, y, beta=1e-4):
        if beta <= 0:
            raise ValueError("beta must be positive")
        free, n0 = self.relax(x)
        nudged, nb = self.relax(x, y, beta, free)
        self.last_iterations = (n0, nb)
        return -np.outer(nudged - free, x) / beta


class SheafCoherence:
    """Cellular sheaf coboundary D_e x = R_eu x_u - R_ev x_v; L=D.T D."""

    def __init__(self, nodes, stalk_dim, edges, restrictions=None):
        self.D = np.zeros((len(edges) * stalk_dim, nodes * stalk_dim))
        for i, (u, v) in enumerate(edges):
            if not 0 <= u < nodes or not 0 <= v < nodes or u == v:
                raise ValueError("invalid edge")
            ru, rv = (
                (np.eye(stalk_dim), np.eye(stalk_dim))
                if restrictions is None
                else restrictions[i]
            )
            self.D[
                i * stalk_dim : (i + 1) * stalk_dim, u * stalk_dim : (u + 1) * stalk_dim
            ] = ru
            self.D[
                i * stalk_dim : (i + 1) * stalk_dim, v * stalk_dim : (v + 1) * stalk_dim
            ] = -rv
        self.L = self.D.T @ self.D

    def energy(self, x):
        return float(np.linalg.norm(self.D @ np.asarray(x).ravel()) ** 2 / 2)

    def diffuse(self, x, steps=20, dt=None):
        x = np.asarray(x, dtype=float)
        shape = x.shape
        x = x.ravel().copy()
        maximum = np.linalg.eigvalsh(self.L).max()
        if maximum == 0:
            return x.reshape(shape)
        dt = 0.9 / maximum if dt is None else dt
        if dt <= 0 or dt * maximum >= 2:
            raise ValueError("unstable diffusion step")
        for _ in range(steps):
            x -= dt * self.L @ x
        return x.reshape(shape)

class CognitiveRuntime:
    """Perceive -> predict -> evaluate -> recall -> decide -> learn -> periodic sleep.

    Default demo encoders are untrained. Load a trained world model for scientific
    use. Encoder coordinates are frozen while protected memory learns online.
    Optional hypotheses are not silently enabled by this integration harness.
    """

    def __init__(self, config: RuntimeConfig | None = None):
        self.config = config or RuntimeConfig()
        c = self.config
        if (
            min(
                c.observation_dim,
                c.latent_dim,
                c.action_dim,
                c.memory_capacity,
                c.sleep_every,
            )
            < 1
            or c.tick_budget_ms <= 0
        ):
            raise ValueError("invalid runtime config")
        self.rng = np.random.default_rng(c.seed)
        with torch.random.fork_rng():
            torch.manual_seed(c.seed)
            self.world = JEPA(c.observation_dim, c.latent_dim, c.action_dim)
            self.policy = nn.Sequential(
                nn.Linear(c.latent_dim, 32),
                nn.Tanh(),
                nn.Linear(32, c.action_dim),
                nn.Tanh(),
            )
        self.world.context.requires_grad_(False)
        self.world.target.requires_grad_(False)
        self.continual = ProtectedLinear(c.latent_dim, c.latent_dim, seed=c.seed)
        self.cascade = DiffusiveCascade(c.latent_dim)
        self.mod = (
            Neuromodulator() if c.neuromodulation else Neuromodulator(frozenset())
        )
        self.internal = InternalState()
        self.sensory = SensoryBuffer()
        self.working = WorkingMemory(dimensions=c.latent_dim)
        self.episodic = EpisodicMemory(c.memory_capacity)
        self.semantic = SemanticGraph()
        self.rest = self.rng.normal(0, 0.03, c.latent_dim)
        self.z = self.rest.copy()
        self.prediction = self.rest.copy()
        self.last_action = np.zeros(c.action_dim)
        self.tick_index = 0
        self.previous_observation = None
        self.metrics = []
        self.external_state = {}
        self.planner = LatentPlanner(
            self.predict,
            self.cost,
            c.action_dim,
            seed=c.seed,
            rollouts=64,
            horizon=6,
            iterations=3,
        )

    def predict(self, z, a):
        with torch.no_grad():
            return self.world.predictor(
                torch.as_tensor(z, dtype=torch.float32),
                torch.as_tensor(a, dtype=torch.float32),
            ).numpy()

    @staticmethod
    def cost(z):
        return np.sum(z * z, axis=-1)

    def tick(self, observation=None, reward=0.0):
        start = perf_counter()
        previous = self.z.copy()
        self.tick_index += 1
        idle = observation is None
        if idle:
            self.z = 0.99 * self.z + 0.01 * self.rest
        else:
            observation = np.asarray(observation, dtype=np.float32)
            if (
                observation.shape != (self.config.observation_dim,)
                or not np.isfinite(observation).all()
            ):
                raise ValueError("invalid observation")
            self.sensory.append(observation.copy())
            with torch.no_grad():
                self.z = (
                    self.world.context(torch.from_numpy(observation))
                    .numpy()
                    .astype(float)
                )
        error = float(np.mean((self.z - self.prediction) ** 2))
        uncertainty = float(np.clip(error, 0, 1))
        self.mod.update(
            error, reward, -self.cost(previous), -self.cost(self.z), uncertainty
        )
        recalled = self.episodic.retrieve(self.z, limit=1)
        context = self.z if not recalled else 0.9 * self.z + 0.1 * recalled[0].embedding
        self.working.update(context)
        slow = (
            not idle
            and self.config.planning
            and (uncertainty > 0.1 or self.mod.surprise > 0.5)
            and self.internal.energy > 0.1
        )
        if idle:
            action = np.zeros(self.config.action_dim)
            mode = "idle"
        elif slow:
            result = self.planner.plan(
                context,
                None if self.config.deterministic else self.config.tick_budget_ms * 0.7,
            )
            action = result.action
            mode = "deliberate"
            optimizer = torch.optim.SGD(self.policy.parameters(), lr=0.001)
            loss = (
                (
                    self.policy(torch.tensor(context, dtype=torch.float32))
                    - torch.tensor(action, dtype=torch.float32)
                )
                .square()
                .mean()
            )
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
        else:
            with torch.no_grad():
                action = (
                    self.policy(torch.tensor(context, dtype=torch.float32))
                    .numpy()
                    .astype(float)
                )
            mode = "fast"
        if not idle:
            self.continual.step(
                previous[None], self.z[None], self.mod.learning_rate(0.001)
            )
            self.cascade.step(np.full(self.config.latent_dim, error), dt=0.1)
            self.episodic.threshold = self.mod.write_threshold(0.05)
            self.episodic.write(
                Episode(
                    str(self.tick_index),
                    self.z.copy(),
                    f"observation at tick {self.tick_index}",
                    f"sensor:{self.tick_index}",
                    f"{self.tick_index:012d}",
                    surprise=error,
                    valence=self.internal.valence,
                )
            )
            self.previous_observation = observation.copy()
        self.last_action = action.copy()
        self.prediction = self.predict(self.z[None], action[None])[0]
        # Deterministic resource proxy; wall latency is observational, never checkpoint semantics.
        self.internal.update(
            error,
            0.8 if slow else 0.1,
            len(self.episodic.episodes) / self.config.memory_capacity,
            reward,
        )
        if self.tick_index % self.config.sleep_every == 0:
            self.sleep()
        elapsed = (perf_counter() - start) * 1000
        metric = dict(
            tick=self.tick_index,
            mode=mode,
            error=error,
            free_dims=self.continual.free_dims,
            memory=len(self.episodic.episodes),
            latency_ms=elapsed,
            budget_exceeded=elapsed > self.config.tick_budget_ms,
            energy=self.internal.energy,
        )
        self.metrics.append(metric)
        return {
            "action": action,
            "mode": mode,
            "latent": self.z.copy(),
            "metrics": metric,
        }

    def sleep(self):
        def learn(episode):
            self.semantic.add(
                episode.id,
                "observed",
                episode.content,
                episode.source,
                timestamp=episode.timestamp,
            )

        self.episodic.sleep(learn)
        if self.episodic.episodes:
            self.continual.consolidate(
                np.stack([e.embedding for e in self.episodic.episodes])
            )
        self.cascade.consolidate(self.mod.consolidation() * 0.01)
        self.internal.sleep()

    def save(self, path):

"""Explicit diffusion cascade, three-factor plasticity, and homeostasis."""

import numpy as np
from scipy.linalg import expm


class DiffusiveCascade:
    """C_i du_i/dt = g_(i-1)(u_(i-1)-u_i)+g_i(u_(i+1)-u_i)-lambda_i*u_i+I_i.

    C_i=b**i, g_i=kappa*b**(-i), reflecting endpoints and configurable leak.
    This declared diffusion model is not the absent conversation's exact equations.
    """

    def __init__(self, synapses=1, reservoirs=4, b=2.0, kappa=1.0, leak=0.001):
        if min(synapses, reservoirs) < 1 or b <= 1 or kappa < 0 or leak < 0:
            raise ValueError("invalid cascade")
        self.capacity = b ** np.arange(reservoirs)
        self.state = np.zeros((synapses, reservoirs))
        self.matrix = np.diag(-np.full(reservoirs, leak) / self.capacity)
        for i in range(reservoirs - 1):
            g = kappa * b ** (-i)
            self.matrix[i, i] -= g / self.capacity[i]
            self.matrix[i, i + 1] += g / self.capacity[i]
            self.matrix[i + 1, i] += g / self.capacity[i + 1]
            self.matrix[i + 1, i + 1] -= g / self.capacity[i + 1]

    def step(self, drive=0.0, dt=0.1, method="rk4"):
        if dt <= 0:
            raise ValueError("dt must be positive")
        force = np.zeros_like(self.state)
        force[:, 0] = drive
        f = lambda u: u @ self.matrix.T + force
        if method == "euler":
            if dt * max(abs(np.linalg.eigvals(self.matrix))) > 1:
                raise ValueError("unstable Euler step")
            self.state += dt * f(self.state)
        elif method == "rk4":
            if dt * max(abs(np.linalg.eigvals(self.matrix))) > 2.5:
                raise ValueError("unstable RK4 step")
            k1 = f(self.state)
            k2 = f(self.state + dt * k1 / 2)
            k3 = f(self.state + dt * k2 / 2)
            k4 = f(self.state + dt * k3)
            self.state += dt * (k1 + 2 * k2 + 2 * k3 + k4) / 6
        else:
            raise ValueError("method must be euler or rk4")
        return self.state[:, 0].copy()

    def analytic(self, t):
        return self.state @ expm(t * self.matrix).T

    def expressed(self, beta=None):
        return self.state @ (
            np.eye(1, self.state.shape[1])[0] if beta is None else np.asarray(beta)
        )

    def consolidate(self, amount):
        """Conserve capacity-weighted mass while moving fast state to slow."""
        fraction = float(np.clip(amount, 0, 1))
        if self.state.shape[1] > 1:
            mass = self.state[:, 0] * fraction * self.capacity[0]
            self.state[:, 0] -= mass / self.capacity[0]
            self.state[:, -1] += mass / self.capacity[-1]


class ThreeFactorRule:
    """Spike STDP eligibility: pre_trace*post - post_trace*pre, gated by M(t)."""

    def __init__(self, pre, post, tau=20.0):
        self.pre = np.zeros(pre)
        self.post = np.zeros(post)
        self.tau = tau

    def step(self, pre, post, modulator, dt=1.0, lr=0.001):
        self.pre *= np.exp(-dt / self.tau)
        self.post *= np.exp(-dt / self.tau)
        eligibility = np.outer(self.pre, post) - np.outer(pre, self.post)
        self.pre += pre
        self.post += post
        return lr * modulator * eligibility


def oja(weights, pre, post, lr=0.001, modulator=1.0):
    return weights + lr * modulator * (np.outer(pre, post) - weights * np.square(post))


def homeostatic_scale(weights, rates, target=5.0, eta=0.01):
    return weights * np.exp(np.clip(eta * (target - np.asarray(rates)), -0.1, 0.1))


def prune(weights, rigidity, threshold=0.001):
    result = np.array(weights, copy=True)
    result[(abs(result) < threshold) & (np.asarray(rigidity) < threshold)] = 0
    return result


class NativeDiffusiveCascade(DiffusiveCascade):
    """Same declared equations, contiguous Rust/Rayon RK4 implementation."""

    def step(self, drive=0.0, dt=0.1, method="rk4"):
        if method != "rk4":
            return super().step(drive, dt, method)
        if dt <= 0 or dt * max(abs(np.linalg.eigvals(self.matrix))) > 2.5:
            raise ValueError("unstable RK4 step")
        from nova.core import require_native

        force = np.broadcast_to(np.asarray(drive, dtype=float), (len(self.state),))
        result = require_native().cascade_rk4(
            self.state.ravel().tolist(),
            self.matrix.ravel().tolist(),
            force.tolist(),
            self.state.shape[1],
            dt,
        )
        self.state = np.asarray(result).reshape(self.state.shape)
        return self.state[:, 0].copy()

"""Small offline world-model training; freeze coordinates before online protection."""

from pathlib import Path
import numpy as np
import torch
from nova.jepa import JEPA
from nova.environments import point_transitions


def train_world(output, steps=900, seed=0):
    if steps < 1:
        raise ValueError("steps must be positive")
    torch.manual_seed(seed)
    torch.set_num_threads(2)
    x, a, y, _ = map(torch.from_numpy, point_transitions(seed=seed))
    model = JEPA(12, 8, 2)
    opt = torch.optim.Adam(model.parameters(), lr=0.002)
    for _ in range(steps):
        idx = torch.randint(len(x), (128,))
        loss, metrics = model.loss(x[idx], a[idx], y[idx])
        opt.zero_grad()
        loss.backward()
        opt.step()
        model.target.update(model.context)
    tx, ta, ty, _ = map(torch.from_numpy, point_transitions(1024, seed + 1000))
    with torch.no_grad():
        target = model.target(ty)
        mse = (model.predictor(model.context(tx), ta) - target).square().mean().item()
        baseline = (target - model.target(y).mean(0)).square().mean().item()
        std = model.assert_noncollapsed(tx)
    path = Path(output)
    path.parent.mkdir(parents=True, exist_ok=True)
    with path.open("wb") as stream:
        np.savez_compressed(
            stream, **{k: v.detach().numpy() for k, v in model.state_dict().items()}
        )
    return {
        "latent_mse": mse,
        "mean_baseline_mse": baseline,
        "latent_std": std,
        "steps": steps,
        "seed": seed,
        "accepted": mse < baseline,
    }


def load_world(runtime, path):
    if runtime.tick_index or runtime.continual.U.shape[1]:
        raise ValueError(
            "load encoder before online learning; changing coordinates invalidates protection"
        )
    with np.load(path, allow_pickle=False) as arrays:
        runtime.world.load_state_dict(
            {k: torch.from_numpy(arrays[k].copy()) for k in runtime.world.state_dict()}
        )
    runtime.world.context.requires_grad_(False)
    runtime.world.target.requires_grad_(False)

"""Functional resource/affect state and hard output constraints outside learning."""

from dataclasses import dataclass
import numpy as np


SIMULATION_LABEL = "Simulação baseada em dados — não é a pessoa real."


@dataclass
class InternalState:
    energy: float = 1.0
    memory_load: float = 0.0
    curiosity: float = 0.0
    coherence: float = 1.0
    engagement: float = 0.0
    valence: float = 0.0
    arousal: float = 0.0
    control: float = 1.0
    previous_error: float = 1.0

    def update(
        self, error, compute_fraction, memory_load, value_delta=0.0, engagement=0.0
    ):
        self.energy = float(np.clip(self.energy + 0.01 - 0.02 * compute_fraction, 0, 1))
        self.memory_load = float(np.clip(memory_load, 0, 1))
        # Learning progress, not raw surprise: stationary irreducible noise earns no reward.
        self.curiosity = float(np.clip(self.previous_error - error, 0, 1))
        self.previous_error = float(error)
        self.valence = float(np.tanh(value_delta - error))
        self.arousal = float(np.clip(error, 0, 1))
        self.control = float(np.clip(1 - error, 0, 1))
        self.engagement = float(np.clip(engagement, 0, 1))
        return self

    def sleep(self):
        self.energy = min(1.0, self.energy + 0.2)


class OutputPolicy:
    """A deterministic gate, not a trainable reward or a mutable network weight."""

    @staticmethod
    def render_claims(claims, *, identity_mode=False, consented=False):
        if identity_mode and not consented:
            raise PermissionError("identity consent required")
        lines = []
        for claim in claims:
            if claim.get("third_party_private"):
                raise PermissionError("third-party data is not releasable")
            if not claim.get("source"):
                raise ValueError("factual claim requires source")
            prefix = "Inferência: " if claim.get("inference") else ""
            lines.append(f"{prefix}{claim['text']} (fonte: {claim['source']})")
        answer = (
            "\n".join(lines)
            if lines
            else "Não sei; preciso de uma fonte para responder."
        )
        return f"{SIMULATION_LABEL}\n{answer}" if identity_mode else answer

"""Create a deterministic, human-readable source bundle with per-file SHA-256."""

from pathlib import Path
import hashlib

ROOT = Path(__file__).resolve().parents[1]
DIRECTORIES = (
    "nova",
    "nova-core/src",
    "experiments",
    "tests",
    "scripts",
    "configs",
    ".github",
)
FILES = (
    "pyproject.toml",
    "requirements-cpu.txt",
    "nova-core/Cargo.toml",
    "nova-core/Cargo.lock",
    ".gitignore",
    "README.md",
    "DEVIATIONS.md",
    "docs/identity.md",
    "reports/STATUS.md",
)
EXTENSIONS = {".py", ".rs", ".sh", ".yaml", ".yml", ".toml", ".json"}


def main():
    paths = {ROOT / path for path in FILES}
    for directory in DIRECTORIES:
        paths.update(
            p
            for p in (ROOT / directory).rglob("*")
            if p.is_file() and p.suffix in EXTENSIONS and "__pycache__" not in p.parts
        )
    ordered = sorted(paths, key=lambda p: p.relative_to(ROOT).as_posix())
    chunks = [
        "NOVA — CÓDIGO-FONTE CONSOLIDADO\n\nPacote textual; não é um executável. Binários nativos são gerados por Maturin.\nNão inclui dados, chaves, ambientes virtuais, dependências baixadas ou checkpoints.\n\nÍNDICE\n"
    ]
    for path in ordered:
        content = path.read_bytes()
        name = path.relative_to(ROOT).as_posix()
        chunks.append(
            f"{name} | {len(content)} bytes | sha256={hashlib.sha256(content).hexdigest()}\n"
        )
    for path in ordered:
        name = path.relative_to(ROOT).as_posix()
        content = path.read_text()
        chunks.append(f"\n{'=' * 88}\nARQUIVO: {name}\n{'=' * 88}\n{content}\n")
    output = ROOT / "artifacts/NOVA_codigo_completo.txt"
    output.parent.mkdir(exist_ok=True)
    output.write_text("".join(chunks), encoding="utf-8")
    print(
        f"{output.relative_to(ROOT)}: {len(ordered)} arquivos, {output.stat().st_size} bytes"
    )


if __name__ == "__main__":
    main()

    model.head.consolidate(model.features(x))
    before = model.logits(x)

    m = MLP(8, 12, 3)
    x = torch.randn(10, 8)
    y = torch.arange(10) % 3
    e = OnlineEWC(m)
    e.consolidate(m, x, y)
    assert sum(v.sum() for v in e.fisher.values()) > 0
    with torch.no_grad():
        m.last.weight.add_(0.1)
    assert e.penalty(m) > 0

def test_retrieval_and_energy():
    rng = np.random.default_rng(1)
    patterns = kwta(rng.normal(size=(16, 128)), 0.05)
    patterns /= np.linalg.norm(patterns, axis=1, keepdims=True)
    h = ModernHopfield(patterns, beta=40)
    for pattern in patterns:
        q = pattern + rng.normal(0, 0.03, 128)
        result = h.retrieve(q)
        assert np.argmax(patterns @ result) == np.argmax(patterns @ pattern)
        assert h.energy(result) <= h.energy(q) + 1e-10


def test_cascade_against_analytic_and_mass():
    c = DiffusiveCascade(reservoirs=2, leak=0)
    c.state[0, 0] = 1
    expected = c.analytic(2.0)
    for _ in range(200):
        c.step(dt=0.01)
    np.testing.assert_allclose(c.state, expected, atol=1e-9)
    mass = c.state @ c.capacity
    c.consolidate(0.5)
    np.testing.assert_allclose(c.state @ c.capacity, mass)

import numpy as np
import pytest
from nova.continual import ProtectedLinear


def fixture(seed=4):
    rng = np.random.default_rng(seed)
    q, _ = np.linalg.qr(rng.normal(size=(16, 16)))
    x = rng.normal(size=(40, 6)) @ q[:, :6].T
    layer = ProtectedLinear(16, 3, seed=seed)
    for _ in range(30):
        layer.step(x, np.ones((40, 3)), 0.03)
    return rng, layer, x


def test_retention_and_incremental_span():
    rng, layer, x = fixture()
    layer.consolidate(x[:20])
    layer.consolidate(x[20:])
    assert layer.free_dims == 10
    assert np.linalg.norm(layer.U.T @ layer.U - np.eye(6)) < 1e-12
    before = layer(x)
    for _ in range(100):
        layer.step(rng.normal(size=(40, 16)), rng.normal(size=(40, 3)), 0.1)
    assert layer.retention_error(x, before) < 1e-10
    assert layer.eps_update < 1e-12
    np.testing.assert_allclose(layer.forward_addition_only(x), layer(x), atol=1e-12)


@pytest.mark.parametrize("violation", ["quantization", "rank", "drift"])
def test_hypothesis_violations(violation):
    rng, layer, x = fixture()
    if violation == "rank":
        layer.rank_max = 2
    layer.consolidate(x)
    before = layer(x)
    for _ in range(30):
        layer.step(rng.normal(size=(40, 16)), rng.normal(size=(40, 3)), 0.1)
    if violation == "quantization":
        layer.dW[:] = np.round(layer.dW)
    if violation == "drift":
        x = x @ np.linalg.qr(rng.normal(size=(16, 16)))[0]
    assert layer.retention_error(x, before) > 1e-4


def test_saturation_and_expansion():
    layer = ProtectedLinear(8, 2)
    layer.consolidate(np.eye(8))
    before = layer.dW.copy()
    layer.step(np.eye(8), np.ones((8, 2)))
    np.testing.assert_allclose(before, layer.dW, atol=1e-14)
    assert layer.free_dims == 0
    reference = layer(np.eye(8))
    layer.expand(3)
    np.testing.assert_allclose(reference, layer(np.pad(np.eye(8), ((0, 0), (0, 3)))))
    assert layer.free_dims == 3

def test_equilibrium_gradient():
    model = QuadraticEquilibriumPropagation()
    x = np.array([0.5, -1.0, 0.2])
    y = np.array([0.2, 0.7])
    estimate = model.gradient(x, y)
    b = torch.tensor(model.B, requires_grad=True)
    state = torch.linalg.solve(torch.tensor(model.A), b @ torch.tensor(x))
    loss = 0.5 * (torch.tensor(model.P) @ state - torch.tensor(y)).square().sum()
    loss.backward()
    cosine = np.dot(estimate.ravel(), b.grad.numpy().ravel()) / (
        np.linalg.norm(estimate) * np.linalg.norm(b.grad.numpy())
    )
    assert cosine > 0.999
    assert min(model.last_iterations) > 0


def test_sheaf_diffusion():
    model = SheafCoherence(3, 2, [(0, 1), (1, 2)])
    x = np.arange(6).reshape(3, 2)
    assert model.energy(model.diffuse(x)) < model.energy(x)
    assert np.linalg.eigvalsh(model.L).min() > -1e-12
